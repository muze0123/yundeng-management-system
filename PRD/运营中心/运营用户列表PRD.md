# 运营用户列表 PRD

| 项 | 内容 |
|---|---|
| 模块 | 运营中心 / 运营用户列表 |
| 路由 | `index.html?page=ops-user-list` |

| 版本 | v1.3（2026-09-15） |
| 状态 | 已确认原型基线 |

## 1. 背景与目标

为运营团队提供一张覆盖用户全生命周期的"全字段"运营视图：从注册来源、激活行为、团队关系到付费消费与套餐资源，支持按快捷场景一键筛选，并提供"字段解释"弹窗对全部列表字段做口径说明，降低跨团队沟通成本。

## 2. 页面结构

页面严格遵守 `design.md` 规范（v1.1 起），为标准两区块结构（无独立标题卡片、区块无外描边、`p-5 md:p-6`）：

1. **区块 1 · 筛选区块**
   - **一级 Tab（字段分组）**：全部字段、用户识别、来源归因、生命周期行为、团队主体关系、付费消费、套餐资源；位于筛选区块首行，与筛选条件之间以 `line-light` 分割线分隔。
   - **筛选栅格（§5.4）**：`filter-flow` grid（`auto-fill minmax(388px,1fr)`，列距 16px 行距 12px），标签 88px 右对齐带中文冒号、与控件间距 0px，控件基准宽 300px：
     - 关联账号：文本输入（占位"手机号 / 邮箱 / IPID / 团队ID / 团队名"），带右侧清空按钮。
     - 注册类型 / 生命周期阶段 / 渠道分类 / 用户类型 / 团队关系 / 账号状态 / 付费状态：下拉。
     - 注册时间：300px 组合日期区间（开始 至 结束，日历图标居右）。
   - **操作组**：紧跟最后一个查询条件（查询-主按钮、重置-次按钮、`filter-toggle` “收起”/“展开”文字入口，默认展开显示全部，收起后保留前 4 项）。

2. **区块 2 · 数据区块**
   - **列表标题行**：语义标题"用户列表"（16px/600）+ 紧邻总数"共 N 条"（12px ink-muted，随筛选联动）。
   - **列表工具栏**：分割线上方为标题行，下方左侧为状态 Tab（快捷筛选，§5.1 紧凑分段控件），右侧为"导出、字段解释"按钮。
   - **快捷筛选 Tab（11 个）**：今日注册、已登录未付费、已注册未付费、7天内购买、清洗流失用户、到期未续费、启动未支付、流失未付费、直投未激活、多团队用户、首启失败；单击启用（四边 primary 描边 + primary 字 + `#E6F0FF` 底 + 600 字重），再击取消。
   - **KPI 指标卡**：使用现有设计系统汇总卡；随字段分组切换，具体口径见 §5.1。
   - **数据表格（§5.2 `.data-table`）**：表头 `#F0F1F3` 底、`ink-sub` 12px/600、padding 9px 12px；数据行 13px `ink-body`、行分隔线 `line-lighter`、hover `#F3F4F6`；全列左对齐，数字/时间/ID mono；表头吸顶、首列吸附。
   - **分页器（§5.5 三区居右）**：页码导航（≤7 页全显，>7 页首末页 + 当前页 ±1，其余 `…` 折叠）+ 条/页下拉（10/20/50，默认 20）+ 跳页输入框（默认 value=1，跳转成功后重置为 1）+ 统计"共 N 条记录　第 a/b 页"；位于表格右下方 `pt-5`，非独立区块。

## 3. 字段清单与分组

全部字段 Tab 列顺序即下方顺序；其余 Tab 按本节指定顺序展示，并共享字段定义；跨组字段在全部字段中仅出现一次。

### 3.1 用户识别
用户ID、手机号/邮箱、曾用手机号/邮箱、注册时间、注册类型、付费状态、账号状态、测试用户、是否禁用、禁用支付

### 3.2 来源归因
用户ID、手机号/邮箱、注册时间、渠道分类、来源渠道、关键词、来源页面、搜索词、落地页、邀请人/归因人、归属销售

### 3.3 生命周期行为
用户ID、手机号/邮箱、生命周期阶段、流失风险、当前卡点、注册时间、首次下载时间、下载客户端、首次客户端登录、首次加入团队、首次创建环境、首次配置代理、首次成功启动、第二次成功启动、首启失败次数、首启失败原因、首单时间、首单金额、首单产品、复购次数、最近消费时间

### 3.4 团队主体关系
用户ID、手机号/邮箱、初始团队ID、初始团队名、当前团队ID、当前团队名、团队数、是否多团队、是否被邀请、关联账号、首启团队ID、首单团队ID、关联团队、关联团队总消费金额

### 3.5 付费消费
用户ID、手机号/邮箱、付费状态、首次付费时间、首次消费月份、首单金额、首单产品、总付费金额、已消费金额、账户余额、赠送金额、最近消费时间、复购次数、是否拉起支付、最后待支付时间

### 3.6 套餐资源
用户ID、手机号/邮箱、套餐购买次数、环境数、成员数、套餐周期、赠送环境数、赠送成员数、赠送周期、平台代理数、自有代理数、三方代理数、API代理数、最近到期时间、7天内到期、30天内到期

> 排序规则（本次确认）：环境数 → 成员数 → 套餐周期 → 赠送环境数 → 赠送成员数 → 赠送周期，即"成员数"紧随"环境数"之后，"套餐周期"调整到"成员数"右侧。

## 4. 关键交互规则

### 4.1 环境数 / 成员数 拆分气泡

- 全部字段和套餐资源 Tab 下，"环境数"参数右侧显示【!】圆形标记；鼠标移入显示气泡：

  ```
  环境数 x 20
  - 计费环境数 x 10
  - 免费环境数 x 10
  - 赠送环境数 x 0
  ```

- "成员数"列（位于"环境数"右侧）参数右侧同样显示【!】，鼠标移入显示气泡：

  ```
  成员数 x 5
  - 计费成员数 x 3
  - 免费成员数 x 0
  - 赠送成员数 x 2
  ```

- 气泡数值为当前行用户数据（总计 = 计费 + 免费 + 赠送）；支持键盘聚焦和 Escape 关闭；表头【!】悬停显示字段定义；滚动时气泡关闭。

### 4.2 套餐周期 / 赠送三字段

- 套餐周期：参数示例 `2026-09-15 15:07:19 至 2026-10-15 15:07:21`（开始 至 结束，mono 字体）。
- 赠送环境数：参数示例 `10`。
- 赠送成员数：参数示例 `2`。
- 赠送周期：参数示例 `2026-09-15 13:22:07 至 2026-10-15 13:22:11`；无赠送数据显示 `-`。

### 4.3 字段解释弹窗

- 数据区右上"字段解释"按钮打开居中 Modal（§5.6：宽 760px、`max-width:92vw`、遮罩 `rgba(0,0,0,.3)`、圆角 8px、标题栏 16px/600、关闭 × 20px ink-muted、底部操作区按钮居右"知道了"），关闭方式：右上 × / 遮罩点击 / 知道了 / Esc。
- 弹窗按快捷任务定义、快捷任务交互、7 个 Tab 汇总、6 个 Tab 列表字段分区展示；完整文案见 [运营用户字段定义](运营用户字段定义.md)。本次文档未重复列出的既有资源字段继续保留：
  - **成员数**：当前用户下所有企业累计成员总数。
  - **赠送环境数**：当前用户总赠送环境数。
  - **赠送成员数**：当前用户总赠送成员数。
  - **赠送周期**：赠送环境和赠送成员生效开始时间-赠送到期结束时间。
- 弹窗使用 `FIELD_HELP_SECTIONS` 按上下文维护，完整保留生命周期阶段、卡点、失败原因枚举。跨 Tab 的同名字段分别展示，避免退款口径互相覆盖。原文中首单金额、首单产品的表述疑点保留原文，待业务确认；本次仅更新解释文案，不修改快捷任务或汇总计算逻辑。

### 4.4 其他

- 搜索：关联账号关键字对 手机号/邮箱、用户ID、团队ID、团队名 模糊匹配；重置还原全部条件与快捷 Tab。
- 分页跳转/每页条数切换后回到表格顶部；筛选变化重置回第 1 页。
- 导出：点击 Toast 提示"已发起导出任务，完成后可在下载中心查看"（原型反馈，无真实导出）。
- 模块状态（Tab、快捷筛选、关键字、分页）由 App Shell 统一保存/恢复。

### 5.1 分组指标口径（v1.2）

所有分组均以“当前结果”开头，后续指标依次为：

| 分组 | 指标 |
|---|---|
| 全部字段 / 用户识别 | 真实用户、测试用户、禁用用户、信息缺失用户 |
| 来源归因 | 已归因用户、未归因用户、TOP来源渠道、销售链接用户 |
| 生命周期行为 | 首下载率、启动率、成功启动率、首单率、TOP卡点 |
| 团队主体关系 | 多团队用户、团队不一致、首启团队缺失、首单团队缺失 |
| 付费消费 | 真实消费用户、净消费金额、首单用户、复购用户、余额消费用户 |
| 套餐资源 | 有效套餐用户、7天内到期、30天内到期、购买过代理用户、购买过套餐用户 |

- 比率分母为当前结果人数，成功启动率分母为尝试启动人数；分母为零时显示 0.00%。
- 净消费金额为当前结果已消费金额之和；余额消费用户按余额消费记录统计，不能使用当前余额替代。
- 首启/首单团队缺失仅统计已发生对应行为且团队 ID 缺失的用户。
- TOP 按当前结果频次取最高项；空结果为“-”。
- 生命周期行为与付费消费显示 T+1 数据日期；全部字段和套餐资源复用同一套列顺序、资源拆分气泡，气泡支持悬停、聚焦、Escape 和滚动关闭。
- v1.2（2026-09-15）：按七张参考图补齐分组字段和动态指标，团队主体关系更名，筛选按钮简化为“收起/展开”，保留套餐资源新增字段与指定示例。
