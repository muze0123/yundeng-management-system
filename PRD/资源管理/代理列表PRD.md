## 1. 需求概述

### 1.1 背景与问题

平台代理资产分散在供应商、订单、用户和环境数据中，运营人员无法快速回答以下问题：某条代理属于谁、是否已交付、能否正常连接、绑定了哪些环境、何时到期、异常是否由供应商或用户配置造成。依赖临时查询会导致处理慢、敏感凭证暴露风险高、批量操作缺乏审计，且容易把支付成功误认为资产可用。

### 1.2 页面定位

代理列表是全平台代理资产的查询与运营工作台。页面以代理资产为主对象，聚合归属用户、团队、供应商、来源订单、服务周期、绑定环境、检测状态及操作日志，并提供受权限控制的检测、分配、导出和下架能力。

页面不负责代理商品配置、供应商结算、订单退款或用户自有代理管理。支付状态、资产入账状态、连接检测状态必须分别展示，不得相互替代。

### 1.3 目标

| 目标 | 验收指标 |
|---|---|
| 提高资产定位效率 | 管理员可通过资产编号、脱敏 IP、用户、订单号或供应商在 3 次交互内定位目标资产 |
| 提高异常处置效率 | 支持单条和批量检测，检测任务结果可追溯到资产与失败原因 |
| 降低误分配风险 | 过期、不可用、检测中和已下架资产不得分配；跨归属分配由服务端拒绝 |
| 保护敏感数据 | 页面、导出、埋点与审计日志均不展示或记录代理用户名、密码、Token 和完整连接串 |
| 保证高风险操作可追溯 | 分配、批量检测、导出和下架均记录操作人、对象、前后值、结果与请求标识 |

### 1.4 用户故事

1. 作为代理运营，我想按供应商、地区、到期和检测状态筛选代理，以定位异常资源。
2. 作为客服，我想从用户或订单追溯到代理资产及绑定环境，以处理交付与连接问题。
3. 作为平台管理员，我想批量检测代理并查看部分失败明细，以快速评估供应商质量。
4. 作为平台管理员，我想为归属用户的环境重新分配代理，并在提交前确认影响范围。
5. 作为审计人员，我想查看代理详情和操作日志，但不能接触代理凭证。

### 1.5 范围

**一期包含：**

- 代理资产列表、统计摘要、筛选、排序、分页、URL 参数恢复；
- 详情抽屉：资产、归属、订单、服务、绑定环境、检测记录、操作日志；
- 单条/批量检测；
- 为资产归属范围内的环境分配或更换代理；
- 单条/批量下架；
- 按当前筛选条件异步导出脱敏数据；
- loading、空数据、筛选无结果、局部失败、无权限、并发冲突与网络异常状态。

**一期不包含：**

- 手工新增、编辑代理 IP/端口/账号/密码；
- 用户自有代理与代理 API 管理；
- 代理商品、套餐、价格、库存和供应商合同管理；
- 订单支付、退款、续费和供应商结算；
- 自动分配策略配置、自动换线与供应商故障切换；
- 明文凭证查看、复制或导出。

## 2. 角色、入口与主流程

### 2.1 角色与权限

| 角色 | 查看 | 查看详情/日志 | 检测 | 分配环境 | 下架 | 导出 |
|---|---:|---:|---:|---:|---:|---:|
| 超级管理员 | 是 | 是 | 是 | 是 | 是 | 是 |
| 代理运营 | 是 | 是 | 是 | 是 | 是 | 是 |
| 客服 | 是 | 是 | 是 | 否 | 否 | 否 |
| 只读审计 | 是 | 是 | 否 | 否 | 否 | 否 |

权限点：`proxy.read`、`proxy.log.read`、`proxy.check`、`proxy.assign`、`proxy.offline`、`proxy.export`。

前端按权限隐藏高风险入口，服务端对列表字段、对象范围和每次写请求再次鉴权。前端隐藏不构成授权。

### 2.2 页面入口与返回

- 入口：左侧导航“资源管理 / 代理列表”；面包屑显示“资源管理 / 代理列表”。
- 支持从用户详情、订单详情、环境详情带参数进入：`userId`、`orderNo`、`environmentId`。
- 从关联页面进入时自动应用对应筛选，并显示可清除的条件；清除后回到全量代理列表。
- 从详情抽屉跳转关联用户、订单或环境时，在当前 URL 保留筛选、排序、页码；浏览器返回后恢复原位置。

### 2.3 核心流程

```text
进入代理列表
  → 恢复 URL 筛选 / 加载统计与列表
  → 筛选定位代理
  → 查看详情与最近检测结果
  ├─ 发起检测 → 创建检测任务 → 刷新结果/查看失败原因
  ├─ 分配环境 → 校验状态与归属 → 二次确认 → 更新绑定关系
  ├─ 下架代理 → 展示影响环境 → 二次确认 → 下架并解除可分配资格
  └─ 导出 → 按当前筛选创建脱敏导出任务 → 任务中心查看结果
```

## 3. 页面结构与布局

### 3.1 页面骨架

页面复用 `Prototype/系统框架.html` 的 56px 顶栏、220px 可折叠侧栏和主内容承载区，不自建系统壳层。业务内容采用设计系统规定的两区块布局，不额外设置页面标题卡。

```text
┌─ 筛选区 ───────────────────────────────────────────────────────────┐
│ 状态 Tab：全部 / 可用 / 异常 / 检测中 / 已过期 / 已下架             │
│ 关键词、用户、供应商、地区、协议、绑定状态、到期时间、查询、重置      │
└───────────────────────────────────────────────────────────────────┘
┌─ 数据区 ───────────────────────────────────────────────────────────┐
│ 代理列表（共 N 条）                    [批量操作] [导出] [批量检测] │
│ [资产总数] [可用] [异常] [7日内到期]                               │
│ 复选框 + 代理资产表格                                              │
│ 分页器                                                             │
└───────────────────────────────────────────────────────────────────┘
```

### 3.2 响应式与滚动

- 目标桌面宽度为 1280px 及以上；768–1279px 时侧栏可收起，筛选项自然换行为 2/1 列。
- 表格最小宽度 1620px，唯一横向滚动容器是表格外层；操作列右侧 sticky，不能遮挡正文。
- 主内容区负责纵向滚动；弹窗、抽屉内部各自滚动，页面背景锁定。
- 长资产编号、订单号、邮箱、供应商名称使用单行省略与 Tooltip；操作按钮不得被压缩为不可读文本。

## 4. 筛选区

### 4.1 状态 Tab

| Tab | 查询值 | 定义 |
|---|---|---|
| 全部 | 空 | 不限制代理生命周期/检测状态 |
| 可用 | `available` | 未过期、未下架，且最近一次检测成功 |
| 异常 | `unavailable` | 最近一次检测失败；失败不自动下架 |
| 检测中 | `checking` | 存在未结束的最新检测任务 |
| 已过期 | `expired` | `expiresAt < now`，不能分配 |
| 已下架 | `offline` | 已人工或系统下架，不能分配 |

状态 Tab 与其他筛选条件为 AND 关系。检测中优先于可用/异常展示；已下架优先于过期；状态由服务端计算，前端不得仅根据颜色或日期自行改写。

### 4.2 筛选项

| 名称 | key | 类型 | 默认 | 规则 |
|---|---|---|---|---|
| 关键词 | `keyword` | string, ≤100 | 空 | 模糊匹配资产编号、脱敏节点、用户 ID/昵称/脱敏账号；精确匹配订单号；去除首尾空格 |
| 归属用户 | `ownerKeyword` | string, ≤100 | 空 | 匹配用户 ID、昵称、脱敏手机号或邮箱 |
| 供应商 | `vendorId` | select | 全部 | 选项来自启用及历史供应商主数据；历史项标注“已停用”但可查询 |
| 国家/地区 | `countryCode` | select | 全部 | 使用标准国家/地区编码；展示中文名与地区码 |
| 协议 | `protocol` | select | 全部 | `HTTP / HTTPS / SOCKS5` |
| 绑定状态 | `bindingStatus` | select | 全部 | 未绑定 / 已绑定；已绑定指至少关联 1 个未删除环境 |
| 到期时间 | `expiresFrom,expiresTo` | date range | 空 | 闭区间，按北京时间自然日查询；开始时间不可晚于结束时间 |

### 4.3 筛选交互

1. 点击“查询”或在文本输入框按 Enter，应用全部条件并回到第 1 页。
2. 点击“重置”，清除全部条件、状态 Tab 回到“全部”、排序恢复“到期时间升序”，列表回到第 1 页。
3. 条件写入 URL；刷新和浏览器前进/后退后恢复，不保存勾选项。
4. 搜索输入有值时显示清空按钮；清空只修改输入，用户再次查询后才刷新结果。
5. 日期非法时不发请求，在字段下显示“开始时间不能晚于结束时间”。
6. 首次加载失败显示区块错误态和“重新加载”；重新加载保留 URL 条件。

## 5. 数据区

### 5.1 标题、统计与工具栏

- 标题：`代理列表`；右侧展示“共 N 条”，N 为当前筛选总数。
- KPI：资产总数、可用、异常、7 日内到期；统计服从除分页外的当前筛选条件。
- KPI 独立加载；单卡失败显示“加载失败 / 重试”，不得阻塞列表。
- 工具栏：批量操作、导出、批量检测。无权限时不展示对应入口。

**批量操作菜单：**

- 分配环境：必须恰好选择 1 条资产；0 条提示“请选择 1 条代理”，多条提示“一次只能为 1 条代理分配环境”。
- 批量下架：至少选择 1 条可下架资产；混入已下架项时，提交前列出不可处理项并允许仅处理有效项。
- 取消选择：清空当前页与跨页选中记录。

勾选作用域仅为用户显式选择的资产，不提供“选择当前筛选全部”能力。一期最多选 100 条；翻页保留显式勾选，修改任一筛选条件后清空选择并提示。

### 5.2 表格字段

| 列名 | key | 展示规则 |
|---|---|---|
| 复选框 | `selected` | 表头全选/取消当前页可选项；已下架项仍可查看但不可再次下架 |
| 代理资产 | `proxyId,maskedEndpoint` | 主行显示资产编号；次行显示脱敏节点 `103.***.***.27:8201`；不得展示账号、密码和完整连接串 |
| 归属用户 | `owner` | 昵称 + 用户 ID；账号按 `138****2608` 或 `z***@example.com` 脱敏 |
| 供应商 | `vendorName` | 供应商名称；历史停用供应商显示灰色“已停用”标识 |
| 协议/地区 | `protocol,country,region` | 协议 Badge + 国家/地区；数据缺失显示 `—` |
| 来源订单 | `orderNo,deliveryStatus` | 脱敏不适用，完整订单号可见；交付状态仅表示资产入账，不表示代理可用 |
| 服务周期 | `activatedAt,expiresAt` | 到期时间为主；次行显示剩余天数；已过期红色，7 日内到期橙色 |
| 绑定环境 | `boundEnvironmentCount` | 0 显示“未绑定”；大于 0 显示“查看 N 个”，点击打开详情抽屉的环境区 |
| 最近检测 | `checkStatus,latencyMs,lastCheckedAt,failureReason` | 成功显示延迟；失败显示可读原因；检测中显示进度；从未检测显示“待检测” |
| 资产状态 | `lifecycleStatus` | 可用/异常/检测中/已过期/已下架 Badge；文本与颜色同时表达状态 |
| 操作 | `actions` | 查看、检测、更多；更多包含分配环境、下架；按权限与状态控制 |

### 5.3 排序与分页

- 默认排序：`expiresAt asc, proxyId asc`，优先展示临期资产。
- 支持对到期时间、最近检测时间、延迟排序；切换排序后回到第 1 页并清空勾选。
- 默认每页 10 条；支持 10/20/50 条。总页数减少导致当前页越界时回退到最后有效页。
- 分页结构严格采用设计系统：页码、条/页、跳页、总数和当前页统计。

### 5.4 行操作

| 操作 | 前置条件 | 系统行为 |
|---|---|---|
| 查看 | `proxy.read` | 打开 800px 详情抽屉，默认“基础信息”Tab |
| 检测 | `proxy.check`；当前无检测任务；非已下架 | 创建单条检测任务；状态立即变为检测中，完成后刷新该行 |
| 分配环境 | `proxy.assign`；可用且未过期、未下架 | 打开分配环境 Modal；只展示归属用户/团队下有权限且未删除的环境 |
| 下架 | `proxy.offline`；非已下架 | 打开确认 Dialog，展示绑定环境数和影响；确认后置为已下架，不删除历史数据 |

## 6. 详情抽屉

### 6.1 结构

抽屉标题为“代理详情”，宽度 800px，包含四个 Tab：基础信息、绑定环境、检测记录、操作日志。

### 6.2 基础信息

展示资产编号、脱敏节点、协议、国家/地区、供应商、归属用户/团队、来源订单、入账时间、到期时间、当前状态、最后同步时间。凭证字段不返回前端；不能用星号占位暗示可查看。

### 6.3 绑定环境

| 字段 | 说明 |
|---|---|
| 环境编号/名称 | 可跳转环境详情；返回时恢复抽屉与筛选 |
| 环境状态 | 运行中/已停止/异常/已删除 |
| 绑定时间 | 北京时间 `YYYY-MM-DD HH:mm:ss` |
| 操作人 | 操作人昵称 + ID |

环境列表独立分页。已删除环境保留历史关系并标记“已删除”，不计入列表绑定数量。

### 6.4 检测记录

展示任务编号、发起时间、结束时间、结果、出口地区、延迟、失败码与失败原因。仅展示最近 30 天或 100 条，取较小范围。检测结果是当时快照，不保证当前仍可用。

### 6.5 操作日志

展示操作时间、操作类型、操作对象、变更摘要、操作人和请求标识。日志不可编辑；不记录 IP 原文、账号、密码、Token、完整连接串和导出下载地址。

## 7. 检测代理

### 7.1 单条与批量规则

1. 单条检测作用于当前资产；批量检测作用于用户显式选中的 1–100 条资产。
2. 已下架资产不可检测；已存在运行中检测任务的资产不重复创建任务，计入“已跳过”。
3. 提交后立即返回 `taskId`，页面状态改为检测中；前台可见时每 3 秒轮询，离开页面后停止轮询，任务继续执行。
4. 服务端检测出口连通性、协议握手、匿名出口地区和延迟；不向前端返回测试凭证。
5. 批量任务允许部分成功，完成后提示“检测完成：成功 N 条，失败 N 条，跳过 N 条”，可在详情中查看逐条原因。
6. 检测失败只更新检测状态和原因，不自动解绑、下架、退款或修改订单状态。

### 7.2 状态

`queued → checking → success | failed | timeout`。同一资产最新未结束任务具有唯一性；重复提交返回已有任务编号，不创建重复任务。

## 8. 分配环境

### 8.1 Modal 内容

- 顶部展示代理资产编号、脱敏节点、状态、归属用户/团队和当前绑定数量。
- 搜索环境：按环境编号/名称模糊匹配。
- 环境列表：复选框、环境编号/名称、状态、当前代理、最近运行时间。
- 只展示资产归属用户或归属团队范围内、操作者有权管理且未删除的环境。
- 已运行环境允许选择，但提交前必须确认“更换代理可能中断当前会话”；已删除环境不展示。

### 8.2 校验与提交

1. 代理必须为可用、未过期、未下架且当前无检测任务。
2. 至少选择 1 个环境；一次最多 50 个。
3. 同一环境只能绑定 1 条代理；选择已有代理的环境表示替换，确认区列出旧代理资产编号。
4. 多个环境共用同一代理时展示关联风险提示，但一期允许提交。
5. 提交使用 `Idempotency-Key` 和资产 `version`；发生版本冲突时保留选择，提示“代理信息已更新，请确认后重试”。
6. 成功后关闭 Modal、刷新当前行和详情绑定环境 Tab，Toast 提示“已为 N 个环境分配代理”。
7. 部分失败时不关闭 Modal，展示逐项成功/失败；成功项更新，失败项保留勾选以便重试。

## 9. 下架与导出

### 9.1 单条/批量下架

- 下架是生命周期状态变更，不物理删除资产，不影响订单和财务历史。
- 确认 Dialog 标题：“确认下架代理吗？”；正文列出资产数量、绑定环境数量，并说明“下架后不能再分配；已绑定环境不会自动更换代理，可能无法继续连接”。
- 绑定环境数大于 0 时，必须勾选“我已知晓对已绑定环境的影响”后才能确认。
- 已下架资产跳过；检测中资产需先终止/等待检测，服务端返回 `PROXY_CHECK_IN_PROGRESS`。
- 成功后状态变为已下架，移除检测/分配入口，保留查看和日志。

### 9.2 导出

- 导出作用域为当前筛选条件下全部匹配记录，不依赖勾选；确认弹窗显示预计条数与筛选摘要。
- 导出字段：资产编号、脱敏节点、归属用户 ID、归属用户脱敏账号、供应商、协议、国家/地区、订单号、入账时间、到期时间、绑定环境数、检测状态、最近检测时间、资产状态。
- 禁止导出代理账号、密码、Token、完整 IP、完整连接串和供应商内部凭证。
- 提交后创建异步任务，Toast：“导出任务已提交，请前往任务中心查看”。文件名：`代理列表导出_YYYYMMDDHHMMSS.xlsx`，有效期 7 天。

## 10. 数据模型与业务规则

### 10.1 核心对象

| 对象 | 唯一标识 | 核心字段 | 关系 |
|---|---|---|---|
| ProxyAsset | `proxyId` | vendorId、protocol、maskedEndpoint、ownerId、orderNo、expiresAt、status、version | 主对象 |
| ProxyVendor | `vendorId` | name、enabled、serviceRegion | 一个供应商提供多条资产 |
| User/Team | `ownerId/teamId` | displayName、maskedAccount | 一名用户或团队拥有多条资产 |
| Environment | `environmentId` | name、ownerId、status | 与代理为多对一当前关系，另保留历史关系 |
| ProxyCheckTask | `taskId` | status、result、latency、failureCode | 一条代理有多次检测快照 |
| AuditLog | `logId` | action、before、after、operator、requestId | 记录高风险操作 |

### 10.2 业务规则

| 编号 | 规则 |
|---|---|
| B-01 | 支付成功、资产入账、检测成功是三个独立事实；任何一个不得替代另一个 |
| B-02 | 页面和接口永不返回代理密码、Token 或完整连接串；脱敏必须由服务端完成 |
| B-03 | 分配环境必须校验代理与环境的用户/团队归属一致；前端选项过滤不能替代服务端对象级鉴权 |
| B-04 | 检测中、已过期、已下架、最近检测失败的代理不可分配 |
| B-05 | 检测失败不自动下架、解绑、退款或切换供应商 |
| B-06 | 下架不删除订单、检测、绑定历史与审计日志；已绑定环境不自动更换代理 |
| B-07 | 筛选条件为 AND；状态优先级为已下架 > 检测中 > 已过期 > 可用/异常/待检测 |
| B-08 | 时间统一按 Asia/Shanghai 展示，接口使用 ISO 8601；剩余天数按北京时间自然日计算 |
| B-09 | 批量操作最多 100 条，环境分配最多 50 个环境；超过限制前端阻止，服务端再次校验 |
| B-10 | 列表与详情返回 `version`；分配和下架使用乐观锁，禁止覆盖他人刚完成的操作 |

### 10.3 状态枚举

| code | 文案 | 进入条件 | 可执行动作 | 语义色 |
|---|---|---|---|---|
| `pending_check` | 待检测 | 入账后尚无成功/失败结果 | 查看、检测、下架 | info |
| `checking` | 检测中 | 最新任务未结束 | 查看、下架受限 | info |
| `available` | 可用 | 未过期/未下架且最近检测成功 | 查看、检测、分配、下架 | success |
| `unavailable` | 异常 | 最近检测失败/超时 | 查看、检测、下架 | danger |
| `expired` | 已过期 | 到期时间早于当前时间 | 查看、下架 | warning |
| `offline` | 已下架 | 人工或系统下架 | 查看 | neutral |

### 11.2 关键错误码

| 错误码 | 页面行为 | 正式文案 |
|---|---|---|
| `FORBIDDEN` | 关闭写入浮层、刷新权限 | 您没有权限执行此操作 |
| `PROXY_NOT_ASSIGNABLE` | 保留环境选择，刷新代理状态 | 当前代理不可分配，请刷新后重试 |
| `OWNER_SCOPE_MISMATCH` | 标记失败环境，不提交该项 | 环境与代理归属不一致，无法分配 |

| `VERSION_CONFLICT` | 保留输入并拉取最新快照 | 代理信息已更新，请确认后重试 |
| `BATCH_LIMIT_EXCEEDED` | 不提交 | 单次最多操作 100 条代理 |
| `NETWORK_ERROR` | 保留筛选/表单 | 网络异常，请检查网络后重试 |

写操作按钮进入 loading 并防重复点击；同一幂等键只产生一份有效结果。批量操作返回逐项结果，不用一个失败回滚已成功的其他资产。

## 15. 发布与风险

### 15.1 发布

1. 上线前完成权限点初始化、供应商/订单/资产/环境 ID 对齐、凭证字段响应扫描和审计日志验收。
2. 先向超级管理员和代理运营灰度；观察检测成功率、分配失败率、下架误操作和导出量 3 天。
3. 异常时关闭 `proxy_assignment_enabled`、`proxy_offline_enabled` 等写入开关，保留只读查询与历史日志；已创建异步任务继续执行并可追踪。

### 15.2 风险与后续确认

| 编号 | 风险/待确认 | 当前处理 |
|---|---|---|
| O-01 | 供应商是否提供统一的节点、地区和失败码回传 | 一期建立平台标准码映射；未知值显示“供应商未返回” |
| O-02 | 已绑定环境在代理下架后是否自动停机 | 一期不自动停机或换线，只明确告警并记录审计 |
| O-03 | 跨多个环境共用一条代理的风控阈值 | 一期只提示风险，不阻断；后续由风控策略配置 |
| O-04 | 导出文件是否需要水印和审批 | 一期要求审计、7 天过期；审批流作为后续能力 |
