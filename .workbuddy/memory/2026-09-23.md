**关键认知（重要，后续不要再重复侦察）**
- `Prototype/更换代理.html` **只是 legacy 重定向存根**，跳转到 `../index.html?page=proxy-replacement`。真实页面 = 统一入口。
- 真实页面由 4 部分构成：`index.html`（系统壳） + `Prototype/系统框架.css` + `Prototype/app-shell.js` + `Prototype/modules/proxy-replacement.js`。

  - `externalScripts: []` → 「更换代理」**不需要 Chart.js**。

**装配配方（先例 = `exports/发票管理-独立版.html`，已成项目既定约定）**
顺序：文件头注释块 → charset/viewport/标题 → 内联 Tailwind Play CDN → 内联 lucide UMD → Google Fonts(`media="print" onload`异步 + `<noscript>`回退，唯一允许的外链) → 内联 `tailwind.config` → 内联 `<style>系统框架.css` → `<body>` 系统壳 HTML → 内联业务模块 → 内联 app-shell → 单文件导出守卫脚本。
- Tailwind / lucide 内联体**从先例文件按字节区间精确切取复用**（Tailwind `383..407705`、lucide `407715..850145`），保证版本一致且离线可用；**禁止保留** `cdn.tailwindcss.com` / `unpkg.com/lucide` 外链。

**app-shell 必需的 4 处 `file://` 适配（缺一不可）**
1. 默认路由兜底：`resolveRoute(... || 'home')` → `|| '<目标模块id>'`
2. 跳过外部模块加载：`await loadScript(MODULE_FILES[route.id],'module')` → 包一层 `if (!window.YundengModules || !window.YundengModules[route.id]) { ... }`
3. `history.pushState(null,'',url)` → 包 `try/catch`
4. `init()` 中删除 `history.replaceState(null,'',routeHref(...))` → 替换为注释（file:// 下改写地址栏会抛错）
> 导出时**必须保留当前完整导航**，不要照抄先例文件里缺失的条目 —— 先例生成于本模块存在之前（09-18 vs 09-23），那是历史差异不是规范。
