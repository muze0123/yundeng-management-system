## 一、背景与目标

为出海用户提供一个「出海工具导航站」：按网站类型分组展示工具网站卡片，并向访客分发云登指维浏览器等自有产品入口（页脚）。参考 `https://www.partnershare.cn/` 的版式。

原型阶段无真实后端：运营在云登后台「出海吧」模块维护数据，独立页作为**只读消费端**渲染同一份数据，两页面通过同键位 localStorage 打通，运营改完即时生效。

**目标**

1. 运营在后台增删改网站 / 类型后，独立页刷新或跨标签即时呈现，无需发版。
2. 页面可直接作为单文件分发给外部合作方或部署为公开导航站。
3. 精选推荐作为流量位，可由运营通过后台「精选」开关随时调整。

**非目标**

- 页面不做任何写入（不含登录、埋点上报、评论等）。
- 页面不渲染云登后台的顶栏 / 侧栏 / 菜单体系。
- 本期不做 SEO 静态化、不做服务端渲染（数据来自 localStorage）。

## 三、数据读取契约（读端）

字段结构与语义以 `PRD/出海吧PRD.md` 第二章为准，本节只规定**读取端行为**。

- **键**：`yundeng_overseas_nav_v1`
- **结构**：`{ version, types: [{ id, name, icon }], sites: [{ id, name, url, intro, typeId, featured, icon }] }`
- **采用条件**：`JSON.parse` 成功且 `types`、`sites` **均为数组**才采用；否则视为无效。
- **回退种子**：本地无键 / 值损坏 / `file://` 下 localStorage 受限（`try/catch` 静默）时，使用文件内内置种子（12 个类型、28 个网站，结构与契约一致）。种子副本，避免被后续渲染变异影响。
- **只读**：页面**不写入** localStorage。
- **跨标签联动**：监听 `window` 的 `storage` 事件；当 `event.key === 'yundeng_overseas_nav_v1'` 时重新读取数据、把精选 chips 状态重置为「全部」，并整体重渲染（含左侧导航）。
- **顺序语义**：`types` 数组序 = 导航与内容分组顺序；`sites` 数组序 = 组内卡片顺序。
- **图标优先级**：`site.icon` / `type.icon`（上传图 data URL）优先 → 网址域名自动匹配 `https://favicon.im/{host}?larger=true` → 加载失败降级首字母色块头像。

### 4.1 布局骨架

- 外层 `#layoutBody`：横向 flex、`height: 100vh`、`overflow: hidden`。
- 左列 `<aside id="sidebar">`：宽 220px、`flex-none`、白底、右侧 1px `line.light` 描边、整列可滚动、`py-3`。
- 右列：纵向 flex，`min-width: 0`；内含 `<header>`（56px，`flex-none`）+ `<main id="content">`（`flex-1`，纵向 flex）。
- 内容块与页脚为 `#content` 的两个兄弟：内容块 `flex-1`、页脚 `flex-none`。内容不足时页脚贴底，内容超长时随滚动到底。

### 4.2 左侧类型导航（`#typeNav`）

- 每项为 40px 高、圆角 6px、内边距 `0 12px`、图标与文字间距 10px 的 `<a>`；文字 14px / 600 / `ink.title`；图标固定 18×18、`stroke-width: 2.4`。
- **首项固定为「精选推荐」**，使用 Lucide `thumbs-up` 图标（非类型项，不参与类型顺序）。
- 其后按 `types` 数组顺序输出各类型；类型图标取「上传图（20×20、圆角 6px）」或「首字兜底块」（20×20、圆角 6px、`#F0F1F3` 底 + `ink.title` 首字）。
- 每项右侧显示数量（11px、`ink.muted`、400）：精选项 = `featured` 网站数；类型项 = 该类型网站数。
- 状态：默认白底 `ink.title`；hover `bg.hover #F3F4F6`；激活项 `primary.bg #E6F0FF` 底 + `primary #0066FF` 字 / 图标 / 数量。
- 行为：点击按 `href="#group-<id>"` 锚点定位到对应分组（分组带 `scroll-mt-4` 避免贴顶），并立即同步高亮，不等滚动 spy 回填；滚动时按 scroll spy 反向高亮（见第六章）。
- 收起态（`.sidebar-collapsed`）：隐藏文字与数量，导航项改为 40×40 居中图标；容器宽度 220px ↔ 68px（带 200ms 过渡）。

### 4.3 顶栏（`header`）

- 高 56px（`h-14`）、`px-5`、白底、下边框 `line.light`、层级 `z-20`；**仅覆盖右列，不横跨侧栏**。
- 左起第一项为汉堡按钮：32×32、圆角 4px、`menu` 图标 20px，`aria-label="收起/展开导航"` + `aria-expanded`（展开时 `true`），hover 底色 `bg.hover`。点击切换侧栏收起/展开。
- 品牌区：渐变方块（28×28、圆角 8px、`linear-gradient(135deg,#2D6BFF 0%,#7C5CFF 100%)`、白色 `rocket` 图标 16px）+ 平台名称「出海吧」（17px / 700 / `ink.title` / `tracking-wide`）。
- **平台名称「出海吧」三个字统一为标题黑 `#1A1D24`，不做双色处理**（页脚品牌名同口径）。

### 4.4 内容区（`#content`）

- `flex-1 overflow-y-auto flex flex-col`，`tabindex="-1"`；内层内容块 `px-6 py-5`。
- `#groups` 承载全部分组；`#emptyAll` 为整页空态容器（默认隐藏）。
- 分组之间间距 `mb-8`（32px）；分组宫格与标题之间 `mb-3` / `mb-4`（精选组因含 chips 用 `mb-4`）。

### 4.5 页脚（内容区底部，白色背景卡片）

以白底卡片收尾于内容区底部。**内缩卡片式**：左右与底部各留 20px（`mx-5 mb-5`）、8px 圆角、四边 1px `line.light` 描边（不再通栏贴边）、内边距 `px-6 py-8`。栅格：桌面 `2fr / 1fr / auto`（列间距 48px），移动端（< 768px）折叠为单列（列间距 32px）。

- **左列**：品牌标记（28×28 渐变方块 + `rocket`，与顶栏同一标记，不得另造）+ 平台名「出海吧」（15px / 700 / `ink.title`）+ 一句话定位「帮出海 SaaS 找到推广者、跑起联盟、放大用户推荐。先免费接入，跑出数据再升级。」（12px / 行高 20px / `ink.sub`，最大宽 34em）。
- **中列**：栏目标题「产品」（13px / 600 / `ink.body #3A3F4A`）→ 链接「云登指纹浏览器」指向 `https://www.yunlogin.com/`，新标签页打开。
- **右列**：栏目标题「联系方式」→ 三个 **36×36 深色圆角方形按钮**（`ink.title #1A1D24` 底 + 白色图标 18px，Lucide `mail` / `message-circle` / `headphones`；hover 底色切主色 `#0066FF`）：
  - 邮箱：图标本身是 `mailto:service@yunlogin.com` 链接；悬停/聚焦显示邮箱地址浮层。
  - 微信：悬停/聚焦显示**二维码占位槽**，说明文案「微信二维码」。
  - 客服：悬停/聚焦显示**二维码占位槽**，说明文案「24 小时在线咨询」。
  - 浮层与图标同处 `.contact-item` 容器，绝对定位于图标**正上方**（`bottom: calc(100% + 8px)`、右对齐），不横向溢出内容区；`hover` 与 `focus-within` 共用同一声明块；`aria-describedby` 指向浮层 id、浮层 `role="tooltip"`。
  - 二维码占位槽规格：132×132、`bg.page #F7F8FA` 底、1px 虚线 `line #DFE1E5` 描边、圆角 6px、内放 `qr-code` 图标 40px。**源码内以 `TODO` 注释标出替换位**：将占位 `div` 换成 `<img class="qr-slot" src="真实图片路径" alt="...">` 即可，无需改动其它样式。真实微信 / 客服二维码由业务方提供。
- **分割线**：页脚内 `border-t` 1px `line.lighter`，与法务区之间 `mt-8 pt-5`。
- **底部法务行**：左侧「© 版权所有 杭州辰链信息科技有限公司 | 〔徽标〕浙公安网备 33010902003507号 浙ICP备2022019151号-6」，其中「浙公安网备」前带**公安备案徽标**（62×67 透明底 PNG，base64 内嵌，展示高 20px 等比缩放、`alt="公安备案徽标"`、与文字基线对齐）；右侧「服务协议」（`https://www.yunlogin.com/v2/news/userAgreement.html`）与「隐私政策」（`https://www.yunlogin.com/v2/news/privacyAgreement.html`），均新标签页打开。
- **右侧留白**：桌面端（md+）法务行 `pr-16`（64px），为固定定位的「回到顶部」按钮让出点击区，避免遮挡「隐私政策」链接。
- **对比度**：法务行与定位语等小字用 `ink.sub #6E7685`（白底 4.57:1，达 WCAG AA）；**不得**用 `ink.muted #9DA2AC`（2.56:1，不达标）。

### 4.6 回到顶部按钮

- **位置**：`position: fixed`，距视口右 / 下各 24px，`z-index: 40`；独立于页脚，任意滚动位置可见。
- **样式**：40×40 圆形，白底 + 1px `line.light` 描边 + `0 4px 16px rgba(0,0,0,.10)` 投影，Lucide `arrow-up` 图标 18px；hover 图标与描边切主色、投影加深。
- **提示语**：hover 或键盘聚焦时在按钮**左侧**展开「回到顶部」气泡（贴右缘时向上/向下都可能出界，向左最稳）；`hover` 与 `focus-within` 共用同一声明块。
- **可访问性**：`aria-label="回到顶部"` + `aria-describedby` 指向气泡、气泡 `role="tooltip"`。
- **行为**：点击后**线性**滚动回顶部（位移与时间成正比，非原生 `behavior:'smooth'` 的缓动曲线）；时长随距离缩放并限幅 280–900ms；滚动容器为 `#content`；`scrollTop` 已为 0 时不做任何事；系统开启「减少动态效果」时直接跳顶。
- **防遮挡**：按钮点击区需经 `elementFromPoint` 校验不被其它浮层遮挡。

## 五、内容分组与卡片

### 5.1 精选推荐分组（跨类型聚合）

- 渲染条件：`featured === true` 的网站数量 > 0；否则整组不输出。
- 组标题：Lucide `sparkles`（18px、`warning #E7772D`）+「精选推荐」+ 副标「N 个网站」（12px / `ink.muted`）。
- 组标题下方为**类型 chips**：「全部」+ 各类型中**精选数 > 0** 的类型（顺序同 `types`）；每个 chip 后缀等宽数字为该类型的精选数量。
- chip 规格（design.md §5.1 状态 Tab 口径）：28px 高、13px 字、圆角 4px、内边距 `0 12px`；未选中白底 + 1px `line` 描边 + `ink.sub` 字；选中项四边 `1px primary` 描边 + `primary` 字 + `primary.bg #E6F0FF` 底 + 600 字重；相邻 chip 以 `margin-left: -1px` 折叠边线，选中/hover 项提升层级使四边清晰。
- 交互：点击 chip 设置过滤态并**仅重渲染分组区**（不重渲染左侧导航、不改变滚动位置）；`storage` 联动时过滤态重置为「全部」。
- 精选卡片右上角带**橙色斜角标**（34×34、`warning #E7772D`、白字「荐」旋转 45°），纯装饰、不响应指针。

### 5.2 类型分组

- 按 `types` 数组顺序输出；**类型下网站数为 0 时跳过该分组**（不输出空分组）。
- 组标题：类型图标（口径同导航）+ 类型名（17px / 600 / `ink.title`）+ 副标「N 个网站」。
- 分组锚点 `id="group-<typeId>"`；精选组锚点 `id="group-__featured"`；均带 `scroll-mt-4`。

### 5.3 网站卡片（`.site-card`）

- 宫格：`grid-template-columns: repeat(auto-fill, minmax(300px, 1fr))`，间距 12px。
- 整卡为一个 `<a>`（`href` = 网站网址、`target="_blank"`、`rel="noopener noreferrer"`、`tabindex="0"`、`aria-label` = 网站名），`cursor: pointer`。
- 卡内结构（横向 flex、`align-items: flex-start`、间距 12px、内边距 `14px 16px`、白底、1px `line` 描边、圆角 8px）：
  - 网站 logo：40×40、圆角 8px、`object-fit: contain`、底色 `bg.page`；
  - 网站名称：14px / 600 / `ink.title` / 行高 20px，单行截断；
  - 网站简介：12px / `ink.sub` / 行高 18px，**默认 2 行截断**。
- 悬停 / 键盘聚焦：描边转 `line.light`、`box-shadow: 0 2px 8px rgba(0,0,0,.06)`、`translateY(-1px)` 上浮，并把卡片 `z-index` 抬到 30（必须先抬卡片的层级，否则后序卡片会盖住简介浮层）。
- **简介全显浮层**：hover / `focus-within` 时展开，绝对定位于卡片内部下缘之外（`left/right: 12px`、`top: calc(100% - 6px)`），白底、1px `line.light` 描边、圆角 6px、阴影 `0 6px 24px rgba(0,0,0,.12)`、内边距 `10px 12px`、正文 12px / 行高 18px；浮层末尾补一行网站网址（11px / `ink.muted`）。要求**不裁切完整简介、不推动布局**、不受卡片圆角裁切。
- **浮层方向自适应**：卡片贴近内容区底部、下方空间不足以容纳浮层时，为卡片加 `is-flip` 改为**向上展开**（判定：`下方剩余空间 < 浮层高度 + 16` 且 `上方空间 > 浮层高度 + 16`）。判定在 `mouseover`（仅跨入卡片时）与 `focusin` 触发。
- 所有文本渲染前做 HTML 转义。

### 5.4 空态

- 无任何分组（无网站、或全部类型下均无网站）时显示 `#emptyAll`：Lucide `package-open` 40px + 文案「暂无网站数据，请在云登后台「出海吧」中添加」（居中、`py-24`、`ink.muted`）。
- 空态下左侧导航仍按其数据渲染。

## 六、交互与状态

| 交互 | 触发 | 行为 |
|---|---|---|
| 精选 chip 过滤 | 点击 chip | 更新过滤态 → 仅重渲染分组区；导航、滚动位置不动 |
| 简介全显 | 卡片 hover / 键盘聚焦 | 展示完整简介浮层；离开 / 失焦即收起；必要时翻转方向 |
| 侧栏收起 / 展开 | 点击汉堡按钮 | 切换 `.sidebar-collapsed`、宽度 220px ↔ 68px、同步 `aria-expanded`；**状态不持久化**，刷新恢复展开 |
| 分组定位 | 点击导航项 | 按锚点滚动到分组 + 立即高亮 |
| 高亮联动 | `#content` 滚动（passive） | scroll spy：以 `scrollTop + 24` 为判定线，取最后一个 `offsetTop <= 判定线` 的分组作为当前分组；无分组时直接返回不作判定 |
| 跨标签同步 | 其它标签写入 localStorage | 重载数据 → 重置精选过滤为「全部」→ 整体重渲染 |
| 回到顶部 | 点击按钮 | 线性滚动回顶（详见 §4.6） |
| 动效降级 | 系统「减少动态效果」 | 过渡时长降至 0.01ms；回到顶部直接跳顶 |

## 七、视觉规范

- 色板 / 字号 / 圆角 / 阴影全部复用 `design.md`，以 Tailwind 配置镜像内联在页面头部（`design.md` 第七章）；**不得**在页面内另引色值或自造样式体系。
- 圆角：默认 4px、`md` 6px、`lg` 8px；间距沿用 4 / 8 / 12 / 16 / 20 / 24 / 32px 阶梯。
- 字体族：正文 `-apple-system, BlinkMacSystemFont, PingFang SC, …`；**数量 / 数字类**用 `JetBrains Mono`（页面内定义为 `.mono`：`font-family:'JetBrains Mono', monospace` + `font-variant-numeric: tabular-nums`，与后台模块 `.font-mono` 同口径，保证多位数不抖动）。
- 焦点态遵循 `design.md` §5.13 单一指示铁律：按钮 / 链接为 B 类实心描边（`2px solid #0066FF`、`outline-offset: 2px`）；输入类为 A 类柔光环（本页当前无输入控件，规则保留以便扩展，不得两套同时出现）。

## 八、可访问性

- 全部交互元素键盘可达；hover 态必须同步有 `focus-within` / `focusin` 等价路径（简介浮层、联系方式浮层、回到顶部提示语）。
- 关键语义属性：卡片 `aria-label` = 网站名；导航项 `title` = 名称；汉堡按钮 `aria-label` + `aria-expanded`；回到顶部 `aria-label` + `aria-describedby`；浮层 `role="tooltip"`。
- 对比度：正文 / 法务等小字对比度 ≥ 4.5:1（`ink.sub` 4.57:1 达标，`ink.muted` 2.56:1 仅可用于非关键装饰信息）。
- 徽标图片必须有 `alt`；装饰性图标不参与读屏。

## 九、响应式与降级

| 场景 | 表现 |
|---|---|
| ≥ 768px | 页脚三列（`2fr / 1fr / auto`）；法务行左右分列并右侧留 64px |
| < 768px | 页脚单列纵排、法务行纵排；卡片宫格按可用宽度自动减少列数（最小 300px） |
| localStorage 不可用 / 值损坏 | 回退内置种子，不白屏（`file://` 直开可用） |
| favicon 加载失败 | 由全局错误处理替换为首字母色块头像（按名称哈希稳定取色，6 色取自 design.md 语义色） |
| 系统减少动态效果 | 过渡近零、回到顶部直接跳顶 |
| CDN 不可用 | **无降级**：Tailwind / Lucide 来自公网 CDN，离线或内网环境下页面无样式与图标（见开放问题） |

## 十一、验收要点

1. `file://` 直开不白屏：无 localStorage 时回退内置种子（12 类型 / 28 网站）正常渲染。
2. 后台增删改 / 排序 / 精选开关后，独立页刷新或**跨标签即时**反映；跨标签联动时精选 chips 过滤重置为「全部」。
3. 左侧导航：首项「精选推荐」+ 各类型（含数量）；点击滚动定位到对应分组并高亮；滚动时高亮反向联动；收起/展开正常且刷新后恢复展开。
4. 精选推荐分组：跨类型聚合正确；chips 为「全部」+ 精选数 > 0 的类型；点击 chip 过滤生效且不改变滚动位置；无精选网站时整组不出现。
5. 类型分组按后台类型顺序输出，0 网站类型不输出空分组；组标题含数量。
6. 卡片：hover 与键盘聚焦均能展示**完整简介浮层**（2 行截断 → 全显），不裁切、不推动布局；贴近底部时自动改为向上展开；点击卡片新标签页打开网址。
7. 卡片宫格自适应；精选卡片右上角有橙色「荐」角标。
8. 图标三级降级正确：上传图 > favicon 自动匹配 > 首字母色块（断网/失败时降级生效）。
9. 空态文案在无数据时出现。
10. 页脚符合 §4.5：白底卡片、左右与底部各内缩 20px、8px 圆角、四边描边；桌面三列 / 移动端单列；三列内容齐全；联系方式三个图标 **hover 与键盘聚焦**均能展开邮箱地址 / 微信二维码 / 客服二维码浮层，移出即收起，不被内容区裁切；法务行含公司名 + 公安备案徽标（内嵌 data URI，位于「浙公安网备」之前）+ 两个备案号；协议链接地址正确；正文对比度 ≥ 4.5:1。
11. 页脚二维码为占位槽（132×132 虚线框 + 说明文案），源码留有 `TODO` 替换注释；替换为真实图片后无需改动其它样式。
12. 页脚视觉符合参考图（PartnerShare）：栏目标题 `#3A3F4A`；联系方式图标为 36×36 深色圆角方块（白图标，hover 切主色）；栅格 `2fr / 1fr / auto`。
13. 回到顶部按钮符合 §4.6：固定视口右下 24px、40×40 圆形、`aria-label` 与提示语正确；hover / 聚焦显示提示语、移出收起；**真实点击后线性滚动回顶部**（中间采样点符合线性比例，非缓动曲线），最终 `scrollTop = 0`；点击区不被遮挡。
14. chip 内数量数字使用 `JetBrains Mono`（等宽 + 表格数字），不得因类名未定义而回落正文字体。
15. 全页无脚本异常；`prefers-reduced-motion` 下动效降级生效。

## 十二、开放问题

- **真实二维码待提供**：微信与客服二维码目前为占位槽，需业务方提供图片后按 §4.5 的 `TODO` 位置替换。
- **CDN 依赖**：Tailwind / Lucide / Google Fonts 均为公网 CDN。若需离线或内网可用（如随客户端分发），需改为内联产物 —— 可参照 `scripts/export-standalone.py` 对其它独立版页面的内联做法。
- **空类型导航项**：类型下网站数为 0 时内容区不输出分组（§5.2），但左侧导航仍列出该项且数量为 0，点击无处可去；需确认是否应隐藏 0 数量类型项。同理，无精选网站时「精选推荐」导航项仍存在但无对应分组。
- **侧栏收起状态不持久化**：刷新恢复展开。若希望记住用户偏好，可写入 localStorage（需与后台侧栏折叠的持久化口径对齐）。
- **公开部署形态**：当前数据依赖访客本机 localStorage，公开访问只能看到内置种子；正式上线建议改为「后台导出只读快照（JSON 内联或接口）」，数据契约已预留 `version` 字段。
- **与后台模块的文档边界**：本页细则以本文为准，后台侧细则以 `PRD/出海吧PRD.md` 为准；两页共享的 localStorage 契约以其第二章为权威定义。
