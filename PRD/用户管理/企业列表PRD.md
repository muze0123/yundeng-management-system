## 1. 需求概述

### 1.0.1 页面定位

企业列表是云登后台“用户管理”中的企业认证主体运营列表，面向平台超级管理员、企业运营管理员和只读审计人员，对通过用户侧注册/企业认证流程产生的企业主体进行查询、核验和服务状态管理。

页面承接企业认证服务、用户/团队服务的聚合数据，输出企业资料更新、服务启用状态和导出任务。核心决策是识别目标企业、判断认证与服务状态，并在有权限时维护非认证资料或调整服务可用性。

本页不创建企业、不删除企业、不直接修改营业执照、统一社会信用代码、法定代表人等已认证凭证字段，也不承担认证审核流。企业新增由用户侧注册/认证流程产生；认证信息变更应触发独立的重新认证流程。

### 1.0.2 用户场景

| 场景 | 前置条件 | 主路径 | 成功结果 | 中断与恢复 |
|---|---|---|---|---|
| S-01 P0 查询企业 | 用户拥有 `enterprise.read` | 从侧栏进入 → 默认查询 → 输入关键词/筛选 → 查询或翻页 | 展示符合权限范围的企业，筛选和分页口径一致 | 加载失败保留筛选并允许重试；无结果显示搜索空态 |
| S-02 P0 查看详情 | 用户拥有 `enterprise.read`，目标企业存在 | 点击“详情” → 打开右侧详情抽屉 → 查看基本、认证、账号和运营信息 | 不离开列表上下文即可核对企业全貌 | 目标被删除或权限变化时关闭抽屉并显示明确错误 |
| S-03 P0 编辑资料 | 用户拥有 `enterprise.update` | 详情或列表点击“编辑” → 修改可编辑字段 → 校验 → 保存 | 服务端持久化，列表和详情同步刷新，记录审计 | 校验失败保留表单；版本冲突提示刷新；网络失败保留输入 |
| S-04 P0 启用/禁用 | 用户拥有 `enterprise.status.update` | 点击状态开关 → 阅读影响 → 填写原因（禁用必填）→ 确认 | 状态更新；禁用后关联成员会话失效；列表即时刷新 | 重复点击被拦截；失败回滚开关；权限变化时终止提交 |
| S-05 P1 导出 | 用户拥有 `enterprise.export` | 按当前筛选点击“导出” → 确认范围和脱敏规则 → 提交 | 创建异步导出任务并提示任务编号 | 频控或失败时明确提示；任务可在下载任务入口追踪 |
| S-06 P0 无权限直达 | 用户缺少 `enterprise.read` | 通过链接访问 `/user-management/enterprises` | 展示 403 状态，不泄露企业数量或字段 | 提供返回有权页面/申请权限入口 |

创建、删除、批量删除均不适用：企业由认证流程产生且作为租户主体被其它数据引用，本页面不得提供这些入口。

### 1.0.3 边界条件汇总

| 编号 | 触发条件 | 系统规则 | 用户表现与恢复 | 关联 |
|---|---|---|---|---|
| B-01 | 关键词为空或仅空格 | 视为未筛选；不传 `keyword` | 返回默认列表，不报错 | F-01、API-01 |
| B-02 | 关键词超过 50 字 | 前端阻止查询，后端同样校验 | 字段下提示“搜索内容不能超过 50 个字符” | F-01、AC-02 |
| B-03 | 多个筛选同时有值 | 条件间为 AND；“全部”不限制该维度 | 查询后回到第 1 页 | A-01、API-01 |
| B-04 | 企业名称/编号过长 | 表格单行省略；`title` 展示完整值；抽屉展示完整内容 | 不撑破列宽和操作区 | AC-11 |
| B-05 | 敏感字段展示 | 手机号、信用代码、法定代表人默认脱敏 | 有独立权限时可临时查看明文并记录审计；否则入口隐藏 | P-05、A-05 |
| B-06 | 禁用已启用企业 | 禁用原因去空格后 5–200 字；服务端最终校验 | 确认后关联成员会话立即失效，无法登录和创建新任务 | A-07、API-04 |
| B-07 | 启用已禁用企业 | 可填写 0–200 字说明；服务端检查风险/合规冻结 | 成功恢复服务；若被合规冻结则提示不可启用原因 | A-07、E-06 |
| B-08 | 状态操作重复点击或响应未结束 | 前端禁用按钮；请求带 `Idempotency-Key` | 只生成一次状态变更和一条审计记录 | 5.4、AC-07 |
| B-09 | 编辑期间数据被他人更新 | 服务端通过 `version` 乐观锁拒绝覆盖 | 保留本地输入并提示“企业资料已被他人修改，请刷新后重试” | API-03、AC-08 |
| B-10 | 默认列表为空 | 系统未存在企业 | 显示“暂无企业数据”，不提供新增按钮 | E-02 |
| B-11 | 筛选后无结果 | 当前条件匹配数为 0 | 显示“未找到符合条件的企业”，提供“重置筛选” | E-03 |
| B-12 | 表格超过可用宽度 | 只有表格容器横向滚动 | 页面本身不出现横向滚动，操作列保持可访问 | AC-11 |
| B-13 | 导出结果超过单文件上限 | 服务端按 50,000 行拆分文件 | 任务结果展示分卷文件；不截断、不静默丢数 | API-05、API-06 |
| B-14 | 页码因数据变化超出最大页 | 服务端返回总数后回退到最新末页并重新查询一次 | 不展示空白的不存在页 | A-03 |

### 1.1 背景与问题

云登后台已经在用户管理信息架构中预留“企业列表”，并在认证链路中区分 `auth_type=enterprise`。现阶段缺少可执行的页面规格，平台人员无法在统一入口检索企业认证主体、核对企业与主账号/团队关系或受控调整服务状态。

企业主体关联用户、团队、成员、环境、订单与权限。若只做简单 CRUD，容易出现误删租户、越权查看认证材料、直接改写已认证凭证、禁用不生效或导出泄露等风险。因此本需求以“只管理已存在主体、凭证字段只读、敏感信息最小暴露、状态操作可追溯”为核心约束。

### 1.2 目标与成功指标

**一句话目标：**让有权后台管理员在一个列表中准确定位企业认证主体并完成详情核对、非认证资料维护、服务启停和受控导出，同时保证所有敏感读取与写操作可鉴权、可回滚、可审计。

| 指标 | 定义 | 初始目标 | 数据来源 |
|---|---|---|---|
| 查询成功率 | 成功返回列表请求 / 有效列表请求 | 不低于 99.9% | API 监控 |
| 列表性能 | 列表接口 P95 响应耗时 | 不高于 800ms（50 条/页） | APM |
| 写操作成功率 | 编辑与状态更新成功数 / 合法提交数 | 不低于 99.5% | API + 审计 |
| 导出可追踪率 | 有 taskId 且最终可查询状态的导出 / 已接受导出请求 | 100% | 任务服务 |
| 越权泄露护栏 | 未授权读取明文或导出事件数 | 0 | 安全审计 |

### 1.3 用户、角色与任务

| 角色 | 主要任务 | 权限范围 |
|---|---|---|
| 超级管理员 | 查询全量企业、维护资料、启停、导出、查看受控敏感字段 | 全部企业；所有操作仍经服务端校验 |
| 企业运营管理员 | 查询授权范围企业，维护运营资料，启停和导出 | 按授权数据范围；是否可查看明文由独立权限决定 |
| 客服 / 审计只读角色 | 查询与查看详情，协助核对问题 | 只读；默认无敏感明文和导出权限 |
| 无权限用户 | 不应得知企业列表和数量 | 菜单隐藏；直达 403 |

### 1.4 范围与非目标

| 本期包含 | 本期不包含 | 依赖 / 后续 |
|---|---|---|
| 关键词、认证状态、服务状态、提交时间筛选 | 新增企业、删除企业、批量删除 | 企业新增继续由用户侧认证流程产生 |
| 企业列表、分页、默认排序 | 企业认证审核、材料补交、重新认证 | 认证审核模块后续独立建设 |
| 企业详情抽屉 | 直接修改企业法定名称、信用代码、法定代表人、认证材料 | 认证字段变更走重新认证 |
| 编辑非认证运营资料 | 团队、成员、订单、环境的具体管理 | 对应页面通过独立路由承接 |
| 单企业启用/禁用及影响提示 | 批量启停 | 风险控制策略可在后续扩展 |
| 按当前筛选异步导出 | 同步下载、浏览器直接拼装文件 | 下载任务入口依赖任务服务 |

### 1.5 前置约束、事实与假设

| 性质 | 内容 | 影响与处理 |
|---|---|---|
| 已确认事实 | 管理对象是跨租户企业认证主体；支持筛选、详情、编辑、启停、导出；不支持新增/删除 | 本 PRD 与原型必须遵守 |
| 已核实项目口径 | 企业认证至少涉及营业执照、法人/授权人核验和对公信息校验；埋点禁止采集营业执照内容 | 认证字段只读且默认脱敏 |
| 设计假设 | 认证状态采用待审核、已认证、已驳回、已失效四态 | 若认证服务已有不同枚举，以服务端枚举映射替换，不改变页面状态模型 |
| 设计假设 | 可编辑资料限定为展示简称、行业、业务联系人、联系电话、客户负责人和备注 | 避免后台直接改写已认证事实；最终字段由产品/法务评审 |
| 设计假设 | 禁用企业会使关联成员在线会话失效并阻止新登录/新任务 | 若实际只限制部分能力，必须在上线前替换影响文案与服务端规则 |
| 技术约束 | 原型使用内联 Mock 数据；正式实现由服务端 RBAC、对象级权限、乐观锁和审计兜底 | 原型交互不等同于真实授权结果 |

## 2. 信息架构、入口与用户流程

### 2.1 入口与路由

| 入口 | 前置条件 | 路由 / 页面 | 初始参数 | 返回行为 |
|---|---|---|---|---|
| 左侧“用户管理 / 企业列表” | `enterprise.read` | `/user-management/enterprises` / `Prototype/企业列表.html` | `page=1&pageSize=10` | 保持已应用筛选和页码 |
| 企业相关通知深链 | 目标存在且有数据权限 | 同上 | 可携带 `enterpriseId` 并自动打开详情 | 关闭详情后回到列表上下文 |
| 下载任务 | `enterprise.export` | `/task-center/downloads?bizType=enterprise` | 携带导出 taskId | 返回时保持列表条件 |

### 2.2 主流程

```text
进入企业列表
  -> 服务端校验 enterprise.read
     -> 无权限：403
     -> 有权限：加载筛选枚举和默认列表
        -> 查询/分页 -> 查看详情
        -> 编辑非认证资料 -> 校验 -> 乐观锁保存 -> 刷新列表/详情
        -> 启用或禁用 -> 影响确认 -> 幂等提交 -> 状态刷新/失败回滚
        -> 导出当前筛选 -> 二次确认 -> 创建异步任务 -> 通知/下载任务查看结果
```

### 2.3 关键用户旅程

| 阶段 | 用户动作 | 系统响应 | 中断与恢复 | 埋点 |
|---|---|---|---|---|
| 到达 | 从侧栏进入 | 校验权限并加载默认列表 | Error/403 状态可重试或返回 | `enterprise_list_view` |
| 查询 | 组合筛选并查询 | AND 查询、页码重置为 1 | 失败保留条件 | `enterprise_search_submit` |
| 核对 | 打开详情 | 展示聚合快照和字段权限 | 详情失败可局部重试 | `enterprise_detail_view` |
| 编辑 | 修改可编辑资料并保存 | 校验、鉴权、乐观锁、审计 | 冲突保留输入 | `enterprise_update_result` |
| 启停 | 确认影响并提交 | 幂等更新，禁用时失效会话 | 失败回滚 | `enterprise_status_result` |
| 导出 | 确认当前筛选范围 | 创建异步任务 | 任务失败可重试 | `enterprise_export_submit` |

## 3. 页面与交互规格

### 3.0 页面整体结构

#### 3.0.1 整体布局

- 复用 `Prototype/系统框架.html`：左侧导航 220px，可折叠为 68px；顶部栏 56px；主内容区内边距 16px。
- 主内容采用两个白色、8px 圆角、无外描边区块：筛选区；企业列表数据区。区块间距 16px。
- 主滚动容器是主内容区；表格超宽时仅 `.overflow-x-auto` 容器横向滚动。
- 详情使用右侧 800px Drawer；编辑使用居中 760px Modal；状态变更使用 760px Modal；导出使用 600×250px Dialog。
- 768–1279px 侧栏可折叠，筛选项按可用宽度换行；表格保持横向滚动。低于 768px 时侧栏以覆盖层打开，浮层宽度使用 `max-width:100%/92vw`。

```text
App Shell
├─ Sidebar：用户管理 / 企业列表（当前高亮）
├─ TopBar：用户管理 / 企业列表 + 通知 + 账号
└─ MainContent
   ├─ 筛选区：关键词 / 认证状态 / 服务状态 / 提交日期 / 查询 / 重置
   └─ 数据区：标题与总数 / 导出 / 企业表格 / 分页
Global Layer
├─ 企业详情 Drawer
├─ 编辑企业 Modal
├─ 启用/禁用 Modal
└─ 导出确认 Dialog
```

#### 3.0.2 区域详细布局

| 区域 | 职责与组成 | 交互与权限 | 状态与响应式 |
|---|---|---|---|
| 顶部栏 | 当前模块路径、通知、账号 | App Shell 公共能力 | 56px，不被正文遮挡 |

- 列表和普通详情接口只返回脱敏字段；不得先返回明文再由前端遮盖。
- 明文读取使用独立接口、短时授权和字段级审计；明文不得进入 URL、前端持久化、控制台日志或埋点。

## 5. 数据模型、业务规则与状态机

### 5.1 领域对象与关系

| 对象 | 唯一标识 | 关系 |
|---|---|---|
| Enterprise | `enterpriseId` | 企业认证主体；关联一个注册主账号、零到多个团队、多个成员 |
| EnterpriseCertification | `certificationId` | 属于一个 Enterprise，维护认证状态和只读凭证摘要 |
| User | `userId` | 一个用户可作为企业注册主账号 |
| Team | `teamId` | 属于一个 Enterprise；团队数由团队服务聚合 |
| Member | `memberId` | 通过团队/企业归属；成员数按未注销主体聚合 |
| AuditRecord | `auditId` | 记录资料修改、状态变化、敏感读取和导出 |
| ExportTask | `taskId` | 保存筛选快照、任务状态和限时产物 |

### 5.2 枚举与状态机

| 字段 | code | 文案 | 规则 | 语义色 |
|---|---|---|---|---|
| `authStatus` | `pending` | 待审核 | 已提交认证，等待认证服务终态 | warning |
| `authStatus` | `verified` | 已认证 | 认证审核通过 | success |
| `authStatus` | `rejected` | 已驳回 | 认证未通过，可由用户侧重新提交 | danger |
| `authStatus` | `expired` | 已失效 | 证照/认证过期或被撤销 | neutral |
| `serviceStatus` | `enabled` | 启用 | 企业服务可用 | primary |
| `serviceStatus` | `disabled` | 禁用 | 企业服务被后台停用 | neutral |

认证状态与服务状态是两个独立维度：已认证企业可被运营禁用；待审核/已驳回/已失效主体是否可启用由服务端准入规则判断。前端不得以认证 Badge 替代服务状态。

```text
serviceStatus:
enabled --禁用（权限 + 原因 + 幂等）--> disabled
disabled --启用（权限 + 合规校验 + 幂等）--> enabled
```

### 5.3 业务规则清单

| 编号 | 规则 | 实现责任 | 验证 |
|---|---|---|---|
| R-01 | 企业只能由用户侧注册/认证流程创建，本页无创建接口 | 前后端 | UI + API |
| R-02 | 企业不得从本页删除，也不定义删除接口 | 前后端 | UI + API |
| R-03 | 已认证凭证字段只读，变更走重新认证 | 后端 | API |
| R-04 | 筛选条件 AND；默认 `submittedAt desc, enterpriseId desc` | 前后端 | E2E |
| R-05 | 禁用原因必填且写入审计；禁用成功后会话失效 | 后端 | 接口 + 集成 |
| R-06 | 状态更新失败必须保持原状态 | 前端 | E2E |
| R-07 | 导出使用已应用筛选快照，异步生成并审计 | 后端 | 集成 |
| R-08 | 所有列表、详情和导出按数据权限裁剪 | 后端 | 安全测试 |

### 5.4 并发、幂等与一致性

| 场景 | 方案 | 用户表现 |
|---|---|---|
| 编辑并发 | `version` 乐观锁；冲突返回最新快照 | 保留输入，提示刷新后重试 |
| 状态连点 | 前端锁定 + `Idempotency-Key` + 服务端 24 小时幂等 | 只产生一次变更 |
| 列表与详情更新 | 写成功后按 ID 更新列表并重新拉取详情 | 两处状态一致 |
| 导出重复提交 | 10 秒内相同用户、相同筛选哈希复用进行中任务 | 提示已有任务，避免重复文件 |

### 6.2 错误约定

| 错误码 | 前端处理 | 正式文案 |
|---|---|---|

| `INVALID_FILTER` | 定位筛选字段 | 筛选条件不正确，请检查后重试 |
| `VALIDATION_ERROR` | 显示字段级错误 | 使用服务端安全文案 |

| `COMPLIANCE_LOCKED` | 不改变状态 | 该企业处于合规限制状态，暂时无法启用 |

| `INTERNAL_ERROR` | 保留上下文并允许重试 | 系统异常，请稍后重试 |

### 6.3 异步导出任务

- 状态：`queued / processing / success / failed / expired`。
- 创建后立即返回 taskId；当前页不轮询文件内容，只以通知或下载任务入口反馈终态。
- 文件保留 7 天；下载 URL 有效期不超过 10 分钟；过期后可重新创建导出，不复活旧 URL。
- 失败任务可重试，重试创建新 taskId；不得覆盖原任务审计记录。

- 告警：5 分钟内状态更新失败率超过 5%；同一账号 10 分钟内导出超过 5 次；未授权敏感读取不等于成功读取，记录安全告警。

## 9. 非功能性与技术约束

| 类别 | 要求 | 验收 |
|---|---|---|
| 性能 | API-01 P95 ≤800ms；详情 P95 ≤600ms；写操作 P95 ≤1000ms（不含异步导出） | 预发压测和 APM |
| 容量 | 页大小最大 50；导出单卷 50,000 行 | 超限分卷或返回明确错误 |
| 安全 | TLS、服务端 RBAC、对象级鉴权、输出转义、CSRF 防护、幂等 | 安全测试 |
| 隐私 | 默认脱敏；明文短时展示；日志和埋点禁敏感原文 | 审计抽检 |
| 可访问性 | 所有控件有 label/aria；键盘可完成筛选、操作和关闭浮层；状态不只靠颜色 | UI 回归 |
| 兼容性 | Chrome/Edge 最近两个稳定版本；768px 以上无页面级横向溢出 | 多断点回归 |
| 原型技术 | 单文件 HTML + Tailwind CDN + Lucide CDN + 原生 JS；Mock 数据内联 | 双击可预览、控制台无 error |
