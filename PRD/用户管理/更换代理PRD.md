## 1. 需求概述

### 1.0.1 页面定位

“更换代理”是后台用户管理下的售后操作页面，面向运营人员和销售经理，在用户申请更换已购代理时完成账号识别、原代理校验、自动资源替换和结果追踪。

上游为用户已购买的代理资产及当前绑定环境；下游为新代理归属、旧资源释放、云登客户端环境代理与指纹更新。操作者只选择用户和原代理，不能指定新 IP、变更地区或修改代理类型。

本页不承担购买、续费、退款、代理商品配置、环境重新分配或客户端自主申请。错误地替换非本人代理或用旧同步任务覆盖最新环境配置会影响用户使用，必须校验归属和版本。

### 1.0.2 用户场景

| 编号 | 场景与前置条件 | 路径 | 可观察结果 / 恢复 |
|---|---|---|---|
| S-01 | 运营处理未到期已购代理的更换请求 | 用户管理 → 更换代理 → 输入账号 → 输入原 IP → 提交更换 | 自动匹配新 IP，记录旧 / 新 IP，继承到期时间并同步环境 |
| S-02 | 销售经理处理异常但未到期的代理 | 查询到状态为异常的原代理 → 提交 | 异常本身不阻止更换；仍须满足已购、本人及未到期条件 |
| S-03 | 严格匹配库存不足 | 有效代理提交 → 无同地区同类型库存 | 原代理、有效期与绑定关系不变；生成更换失败记录，保留输入 |
| S-04 | 新代理已生效但环境或指纹同步失败 | 查询同步失败记录 → 重试同步 | 保持新 IP，不再次分配资源；原记录结果更新，追加重试日志 |
| S-05 | 用户需要核对绑定环境 | 记录中点击查看详情 → 切换本地 / 云环境 | 只读显示该新代理当前绑定环境，支持搜索和分页 |
| S-06 | 原代理已过期、退款、停用或不属于当前用户 | 输入账号和原 IP → 实时查询 | 明确提示原因，不允许更换，不生成已提交的更换记录 |
| S-07 | 操作人员刷新或离开后返回 | 页面刷新 / 菜单切换后返回 | 原型在同一标签页会话内恢复筛选草稿、已应用条件、排序和分页 |
| S-08 | 未获授权或权限在操作中失效 | 访问路由 / 提交命令 | 生产接口拒绝越权；当前原型尚未接真实权限服务 |

不适用：编辑或删除历史记录、批量更换、导入导出、用户自主申请、审批流。当前不提供通过 URL 预置用户 / IP 筛选的业务深链；根路由参数仅用于进入模块。

### 1.0.3 边界条件汇总

| 编号 | 触发条件 | 规则与界面表现 | 数据与恢复 |
|---|---|---|---|
| B-01 | 账号 / 原 IP 为空，或超过 50 字 | 两项必填；输入最长 50，显示计数；未识别用户时原 IP 禁用 | 不提交；补齐或修改输入后重新查询 |
| B-02 | 用户账号改变 | 立即清空原 IP、代理卡片、错误与提交资格；丢弃旧查询响应 | 重新识别账号，不沿用前一用户资源 |
| B-03 | IP 不存在 / 不属于用户 | 使用 F-03 / F-04 文案，提交不可用 | 不改变资产，不生成更换记录 |
| B-04 | 未购买、已过期、已退款、已停用或已释放 | 原型仅允许 `running`、`abnormal` 且已购未到期 | 卡片可展示；纠正输入后重试；正式状态映射见 O-03 |
| B-05 | 查询通过后提交时资产变化 | 再校验归属、状态、有效期和版本 | 保留表单，提示重新查询；不得继续使用过期快照 |
| B-06 | 没有同地区同类型可用库存 | 不切换地区、不切换类型、不返回原 IP | 保留原资产，写入 `failed`，保留弹窗 |
| B-07 | IP 更换后同步失败 | 保留新 IP，显示 `sync-failed` 及重试入口 | 不回滚到原 IP，不延长到期时间 |
| B-08 | 旧同步失败记录对应的新代理又被替换 | 旧资产显示已释放，无当前绑定环境 | 不允许旧任务重试覆盖最新配置，历史 IP / 地区不改写 |
| B-09 | 连点提交 / 重试 | 原型禁用按钮、校验结果状态；生产须使用幂等键和版本 | 同一次请求只产生一次资产替换；重试不新增更换记录 |
| B-10 | 操作时间起点晚于终点 | 阻止确认 / 查询并显示错误 | 保留已应用结果；结束秒包含该秒所有毫秒记录 |
| B-11 | 查询无结果或无绑定环境 | 列表空态；绑定环境为零时显示“- -” | 重置筛选或更换查询条件；不显示可点击空详情入口 |
| B-12 | 超长地区 / 窄屏 / 多环境 | 表格在自身容器横向滚动，弹窗正文独立滚动 | 不发生页面级横向溢出，关闭与主操作可达 |
| B-13 | 网络写入超时，无法确认是否已经换 IP | 生产建议显示结果确认中，按请求标识查询 | 未查明前不得以新幂等键盲目再发更换；见第 6 章 |
| B-14 | 权限或数据范围变化 | 生产接口返回禁止访问，前端刷新权限态 | 不把无权限伪装为“用户不存在”；不自动重复写入 |
| B-15 | 新代理字段不存在 / 地区历史数据缺失 | 更换失败无新资产时相关字段为“- -”；地区未知显示“- -” | 不能猜测真实地区；Mock 历史补齐规则见 5.3 |

### 1.0.4 Toast 提示汇总

以下 T-01～T-04 为当前原型文案。均显示 5 秒，新提示替换旧提示，不包含可点击操作；记录列表承担持续状态展示。

| 编号 | 触发条件 | 级别 / 正式文案 | 提示后行为 |
|---|---|---|---|
| T-01 | 资源替换完成、同步尚未完成 | 信息：新代理已生效，正在同步环境与指纹 | 关闭弹窗，清空筛选、恢复降序及第 1 页；保留当前每页条数 |
| T-02 | 更换或同步重试全部完成 | 成功：代理更换及环境、指纹同步已完成 | 同一条记录更新为更换成功 |
| T-03 | 环境或指纹同步失败 | 警告：新代理已保留，环境或指纹同步失败，可重试 | 同一条记录显示同步失败及可用重试入口 |
| T-04 | 发起重试时发现旧任务已被替代 | 提示：该代理已被后续更换替代，无需重试旧任务 | 不执行旧任务，刷新当前记录可操作状态 |

生产新增的加载、网络与权限提示见第 7 章，不把库存不足或输入错误统一变成 Toast；它们应保留在原操作上下文中。

### 1.1 背景与问题

当前云登客户端不支持用户自主发起代理更换。用户购买代理后需要更换时，须联系运营或销售经理在后台处理。本需求提供统一入口和历史记录，使处理人员可以核对归属、识别不可更换状态、完成资源替换并处理同步失败。

目前未提供处理耗时、工单量或投诉率基线，因此不虚构效率提升比例。主要风险是换错用户、匹配到不同地区或类型、重复占用资源，以及新 IP 生效后环境 / 指纹配置未同步。

### 1.2 目标与成功指标

目标：让获授权的运营或销售经理完成一次可追溯的代理更换，在严格匹配资源及继承有效期的前提下，能够发现并恢复环境与指纹同步失败。

以下为生产观测建议，指标目标、基线和告警阈值由第 12 章 O-07 确认。

| 指标 | 定义 | 基线 / 目标 | 统计周期与来源 | 责任角色 |
|---|---|---|---|---|
| 资源替换成功率 | 成功分配新资产的有效更换请求数 / 有效更换请求数，按幂等请求去重 | 未采集 / 待确认 | 按日；资产命令结果 | 后端、数据 |
| 首次同步成功率 | 首次同步即成功的更换记录数 / 已结束首次同步的记录数 | 未采集 / 待确认 | 按日；同步任务结果 | 客户端、数据 |
| 同步恢复率 | 通过重试恢复成功的记录数 / 发起过重试的记录数 | 未采集 / 待确认 | 按日；重试日志及任务终态 | 后端、数据 |
| 端到端处理时长 | 从有效提交到环境与指纹同步成功的耗时，报告 P50 / P95 | 未采集 / 待确认 | 按日；请求及任务时间戳 | 后端、运维 |
| 正确性护栏 | 跨用户误换、地区 / 类型降级、重复生效、有效期改变事件数 | 不允许发生 | 持续；一致性检查与审计 | 后端、测试 |

点击“提交更换”不等于更换成功；新资产分配成功不等于同步成功。尚未结束的任务单独统计，不能提前计入成功或失败。

### 1.3 用户、角色与任务

| 用户 | 任务 | 使用边界 |
|---|---|---|
| 运营人员 | 定位用户代理、发起更换、追踪与重试同步 | 用户明确的目标使用者，实际账号授权见 O-02 |
| 销售经理 | 为联系自己的用户处理代理更换、核对结果 | 数据范围、是否仅可处理归属客户待确认 |
| 当前后台管理员演示账号 | 在原型中操作 Mock 数据 | 不代表所有管理员自动拥有生产权限 |
| 客户端用户 | 提出售后诉求、使用更换后的代理 | 本期无自主发起或审批确认入口 |

### 1.4 范围与非目标

| 本期功能 | 不包含 | 生产依赖 |
|---|---|---|
| 更换记录查询、排序、分页 | 导出、批量更换、修改或删除记录 | 记录查询服务 |
| 用户识别、原代理查询与资格校验 | 相同 IP 不同端口的二次选择、手工指定新 IP | 用户及资产服务 |
| 同地区同类型自动分配、继承有效期、释放原资源 | 更改地区 / 类型、续费、退款、审批、次数配额 | 库存、归属事务 |
| 同步结果和失败重试 | 环境重新分配、解绑、星标修改 | 本地 / 云环境与指纹同步服务 |
| 只读绑定环境详情 | 客户端自主申请页面 | 当前绑定关系查询 |

### 1.5 前置约束与假设

已确认：同一用户不会拥有相同 IP、不同端口的多条代理；只允许已购未到期代理；异常未到期可更换；严格匹配国家、省份、城市及三种类型；次数不限；新代理继承原到期时间；新 IP 已生效后同步失败不回滚。

费用、角色矩阵、完整状态映射、行政地区编码、同步成功回执、资源释放后重新入池策略以及生产容量尚未确认，统一记录在第 12 章。文案使用“所属地区”只是表达调整，不改变已确认的匹配粒度。

### 2.2 主流程

```text
进入模块 → 查询记录 / 点击更换代理
                     ↓
              识别完整用户账号
                     ↓
              实时查询原代理 IP
                     ↓
       校验本人、已购、状态、到期时间
           ├─ 不通过 → 字段提示，禁止提交
           └─ 通过 → 提交并再次校验版本
                         ↓
                 严格匹配地区和类型
           ├─ 无库存 → 失败记录；原资产不变
           └─ 有库存 → 新资产归属用户；继承到期时间
                         ↓
                 旧资产解绑并释放
                         ↓
                 同步绑定环境与指纹
           ├─ 成功 → 更换成功
           └─ 失败 → 保留新资产 → 重试同步
                                   ├─ 仍是有效任务 → 更新原记录
                                   └─ 已被后续更换替代 → 禁止旧任务覆盖
```

#### 3.1.3 列表字段定义

| 列名 | 原型 key / 来源 | 类型与展示 | 空值 / 特殊状态 |
|---|---|---|---|
| 用户ID | `record.userId` | string，等宽；示例 `100001` | 记录必须关联用户 |

| 更换结果 | `result,reason` | 结果 Badge，下方可显示原因 | 与代理状态相互独立 |
| 操作人 | `operator` 的展示名称 | 仅姓名，例如“陈晓”，不显示“· 运营” | 管理员演示账号仍按自身显示名称展示 |

| 操作 | 结果及当前新资产 | 符合资格显示“重试同步” | 同步中显示“正在同步…”；失效显示“已被后续更换替代”；其余“- -” |

地区例子：`198.51.100.80` 下一行 `中国-香港`。实际渲染使用所属地区数据，不把所有记录替换成例子。原型展示时去掉相邻重复地区层级，例如“中国-上海-上海”在列表显示“中国-上海”；资源匹配仍使用完整地区信息。

#### 3.1.4 查询、排序与分页行为

1. 查询按钮或筛选表单 Enter 应用全部条件并回第一页；只有清空按钮不立即刷新结果。
2. 重置清空条件，恢复全部操作人、全部结果、操作时间降序和第 1 页，保留当前每页条数。
3. 点击操作时间表头在升序 / 降序之间切换，回第 1 页；表头同步 `aria-sort` 和方向高亮。
4. 页码不多于 7 页时全部展示；超过时保留首尾与当前页相邻页，其余省略。
5. 跳页默认值 1，Enter 生效；空值按 1，越界回到最近合法页，小数取整数；完成后重置为 1。
6. 筛选或任务结果变化导致页数减少时，页码收敛至有效范围；零记录按第 1/1 页显示。
7. 会话保存包含草稿和已应用条件；仅修改草稿后刷新，不能把尚未查询的草稿误应用到列表。
8. 首次进入和手动刷新读取当前资产信息；Mock 无跨标签页实时同步，也没有生产服务订阅，不能据此宣称跨客户端实时性。

### 3.2 更换代理弹窗

#### 3.2.1 字段与联动

| 字段 / key | 必填 | 类型 / 长度 | 提示语 | 校验与联动 |
|---|---|---|---|---|
| 用户账号 `account` | 是 | 单行文本，最多 50 | 请输入用户ID/用户手机号/邮箱 | 按完整 ID / 手机号 / 邮箱识别唯一用户；邮箱忽略大小写 |
| 原代理IP `source-ip` | 是 | 单行文本，最多 50 | 请输入用户原代理IP | 账号识别前禁用；识别后查询本人资产；无需端口选择 |

两项框内右侧显示 `当前字符数/50`。原型按 `input.value.length` 计数，maxlength 与输入事件共同截断超过 50 的内容。普通筛选的模糊搜索语义不用于账号识别。

原型账号输入防抖 280ms、IP 查询防抖 320ms，用于模拟实时查询；这不是生产接口耗时承诺。每次账号或 IP 改变须使旧查询结果失效，避免晚到响应恢复错误的提交资格。

#### 3.2.2 代理信息卡片

原 IP 查询成功后在输入框下方展示：代理 IP、所属地区、代理类型、最近登录时间、代理状态、到期时间。前四项为用户要求和匹配依据，状态及到期时间为原型补全，用于解释资格拦截。无查询结果时不保留前一个 IP 的卡片。

状态不满足更换条件时仍可显示该用户资产信息，但提交按钮禁用并显示原因。仅不存在资源或非本人资源时不展示资产卡片。

#### 3.2.4 固定说明文案

标题：**说明**。

1. 按原代理所属地区和代理类型，自动分配其他可用 IP；无匹配资源时保留原代理。
2. 新代理继承原到期时间，更换后原代理立即解绑并释放。
3. 同步更新绑定环境的代理与指纹信息。同步失败时保留新 IP，可在更换记录中重试同步。

#### 3.2.5 操作规则

| 操作 | 条件 | 行为与反馈 |

## 4. 权限、可见性与数据安全

### 4.1 权限矩阵

以下为生产能力拆分建议，权限码和角色授权尚未确认（O-02）。不在文档中擅自授予全部运营、销售或管理员全量访问权。

| 能力 | 建议权限码 | 前端表现 | 服务端责任 |
|---|---|---|---|
| 查看列表 | `proxyReplacement.read` | 有权才显示菜单与内容 | 校验记录范围、用户 / 团队范围 |
| 识别用户、查询原资产 | `proxyReplacement.create` | 更换弹窗内可查询 | 对被查询用户及资产再次鉴权 |
| 发起更换 | `proxyReplacement.create` | 有权才显示更换代理 | 校验主体、归属、状态、版本与库存 |
| 查看绑定环境 | `proxyReplacement.environment.read` | 有权才显示详情入口 | 返回本代理当前有权环境 |
| 重试同步 | `proxyReplacement.retry` | 权限与任务资格同时满足才显示 | 校验任务、资产版本、当前归属与环境范围 |

当前 Mock 沿用页面管理员显示名，无真实 RBAC。生产不能把“按钮可见”当作权限校验。纯只读用户如被授权，不能执行更换或重试。

### 4.2 数据处理

- 用户已明确本模块手机号和邮箱不脱敏；IP 也需完整展示用于定位。真实数据读取仍须受对象范围控制。
- 操作人展示名不带角色后缀；生产筛选应按稳定 `operatorId`，不得仅以同名字符串区分人员。角色可留在审计上下文，但不展示为列表后缀。
- 不展示、返回或采集代理连接密码、Token、完整认证连接串。
- 历史记录不允许通过本页面删除或修改；重试日志追加保存。留存期见 O-06。
- 手机号、邮箱、完整 IP、查询原文不进入前端埋点、通用错误日志。业务记录因售后追踪需要保存相应字段，应受控存储、访问和审计。

## 5. 数据模型、业务规则与状态机

### 5.1 领域对象与关系

| 对象 | 唯一标识 | 核心字段 | 关系 |
|---|---|---|---|
| 用户 | `userId` | phone、email | 一个用户持有多项代理资产，有多条更换记录 |
| 代理资产 | `assetId`，原型为 `id` | owner、ip、area、type、status、expiresAt、purchased、version | 更换原资产与新资产是不同对象；IP 不作为永久记录主键 |
| 更换记录 | `recordId`，原型为 `id` | userId、oldIp、oldArea、newIp、newArea、newAssetId、lastLogin、result、reason、operator、operatedAt | 一次有效更换命令一条记录；新资产可为空 |
| 绑定环境 | `environmentId`，原型为 `id` | kind、name、group、star、region、expiresAt、note | 绑定新资产；环境代理和指纹同步分别有结果 |
| 同步任务 | 建议 `syncTaskId` | recordId、assetVersion、各环境同步项及结果 | 生产持久化；原型由延时函数模拟，无独立任务接口 |
| 重试日志 | 原型 `record.retries[]` | operator、time、result | 追加记录；生产建议补充独立日志 ID 与 requestId |

`oldIp / oldArea / newIp / newArea / lastLogin / operatedAt` 为历史快照；新资产状态、有效期、当前绑定关系读取新资产。不能沿后续替换链把历史 `newIp` 改成最新 IP。

### 5.2 状态定义

**更换结果：**

| code | 文案 | 进入条件 | 允许动作 / 后续 |
|---|---|---|---|
| `syncing` | 同步中 | 新 IP 已生效，初次同步或重试执行中 | 查询；成功到 success，失败到 sync-failed |
| `success` | 更换成功 | 新 IP 生效且所需环境 / 指纹全部同步完成 | 查看当前资产和环境；无绑定环境也可成功 |
| `failed` | 更换失败 | 有效提交后未能分配新资产，如无库存 | 无同步重试；可重新发起更换 |
| `sync-failed` | 同步失败 | 新 IP 已生效但至少一项同步失败 | 资产及版本有效时可到 syncing；已被替代时不可重试 |

表单 / 归属 / 状态校验失败没有生效的更换命令，不生成更换记录。更换次数不限不等于库存无限，也不取消并发校验。

**代理状态：**

| 原型 code | 文案 | 可作为原代理更换 | 说明 |
|---|---|---|---|
| `running` | 运行中 | 是，仍须已购且未到期 | 正常运行 |
| `abnormal` | 异常 | 是，仍须已购且未到期 | 已确认异常不是禁止条件 |
| `expired` | 已过期 | 否 | `expiresAt <= 当前时间` |
| `stopped` | 已停用 | 否 | 生命周期状态 |
| `refunded` | 已退款 | 否 | 已退款资产不可更换 |
| `released` | 已释放 | 否 | 历史新资产被后续更换，已无当前用户归属 |

后三类生命周期状态在原型展示上优先于日期派生状态；其他资产到期后显示已过期。完整生产状态字典、检测中及其他未知状态映射待 O-03 确认，不能把本表当作资源系统全部枚举。

### 5.3 业务规则

| 编号 | 规则 | 口径来源 |
|---|---|---|
| R-01 | 原代理必须属于已识别用户，已购买且未到期；已过期、退款、停用禁止，异常未到期允许 | 用户确认 |
| R-02 | 严格匹配国家、省份、城市、类型，排除原 IP；类型仅静态住宅-优质、静态住宅-标准、云平台 | 用户确认 |
| R-03 | 无库存不降级，原资产和环境不变；原型记录 failed | 用户确认不降级；失败记录为原型口径 |
| R-04 | 新代理继承原到期时间，次数不限；原代理立即解绑并释放 | 用户确认；费用未确认 |
| R-05 | IP 生效后同步失败保留新 IP；重试更新原记录，不再次替换、不改原操作人和时间 | 用户确认保留 / 重试；日志细节为原型及生产建议 |
| R-06 | 新代理已被后续替换时，旧记录显示已释放且零当前绑定；旧任务不可覆盖新任务 | 原型补全及一致性要求 |
| R-07 | 到期剩余天数为 `ceil((expiresAt-now)/86400000)`；已到期显示 `max(1,floor((now-expiresAt)/86400000))` 天 | 当前原型展示口径，不改变真实有效期 |
| R-08 | 地区是更换时快照；历史 Mock 按旧资产、新资产或确定的种子记录补齐，保留已有记录与视图 | 原型兼容；生产缺失数据不能按新资产推定历史事实 |
| R-09 | 旧异常资源解除用户归属不等于健康可重新销售 | 生产建议；原型将释放资产留为 released，不自动放回 running 库存 |

### 5.4 并发、幂等与一致性

以下是生产接入建议，尚未由真实服务验证。

- 单次提交携带 `Idempotency-Key` 和原资产版本。同键重发返回同一记录；同键不同参数拒绝。客户端禁用按钮不能替代后端幂等。
- 同一原资产同时更换只允许一个成功；库存占用、新旧归属迁移、有效期继承和记录写入应形成明确事务边界，不能出现两个用户同时持有同一库存。
- 资产替换和客户端同步为不同阶段。新资产事务已完成后同步失败，不回滚归属，不复用原 IP；持久化同步任务以便刷新或进程恢复。
- 同步项绑定新资产版本 / 更换序列；执行前校验最新绑定，过时任务拒绝写入。部分同步重试仅处理未完成项，已完成项须幂等。
- Mock 会对环境代理和指纹重新赋相同新值来模拟重试；没有真实的逐项失败队列，不能据此宣称生产已实现“仅重试失败项”。
- 重试期间权限、到期、停用等变化的处理策略见 O-04 / O-05。原型重试主要验证归属与释放状态，尚不覆盖生产全部生命周期情况。

## 6. 接口与前后端契约

本章为**待技术评审的语义建议**。路径、字段与错误码均未对接真实服务；现有原型使用 sessionStorage 和内存对象，不发起以下 API 请求。

### 6.1 接口清单（建议）

| 编号 | Method / Path | 请求要点 | 响应要点 | 权限 / 失败语义 |
|---|---|---|---|---|
| API-01 | `GET /api/v1/proxy-replacements` | user、oldIp、newIp、operatorId、operatedFrom、operatedTo、result、page、pageSize、sort | items、total；历史快照 + 新资产当前投影 | read；非法筛选 / 无权限 |
| API-02 | `GET /api/v1/proxy-replacements/operators` | keyword | operatorId、displayName | read；数据范围内操作人，不拼角色后缀 |
| API-03 | `POST /api/v1/proxy-replacements/resolve-user` | account | userId、phone、email | create；不存在 / 无权限 |
| API-04 | `POST /api/v1/proxy-replacements/lookup-proxy` | userId、ip | assetId、地区、类型、状态、有效期、lastLogin、version、canReplace、reason | create；归属不符 / 不存在 |
| API-05 | `POST /api/v1/proxy-replacements` | userId、oldAssetId、version；幂等请求头 | recordId、result、原 / 新资产快照、syncTaskId | create；冲突 / 资格变化 / 无库存 |
| API-06 | `GET /api/v1/proxy-replacements/{recordId}` | recordId；可按原请求标识补查 | 命令生效结果、新资产当前信息、同步结果 | read；用于超时后确认是否已生效 |

| API-08 | `POST /api/v1/proxy-replacements/{recordId}/retry-sync` | assetVersion；重试幂等键 | syncTaskId、result、retryLogId | retry；旧任务被替代 / 冲突 |

契约约束：页大小仅 10 / 20 / 50；排序按操作时间升降序，生产建议以记录 ID 作稳定次级排序；时间传输携带时区或使用 UTC，页面统一转北京时间。地区提供完整层级编码及名称，显示去重不能改变匹配编码。原型 `operator` 字符串需映射成生产稳定 `operatorId`。

### 6.2 通用响应与错误建议

返回 `requestId、code、message`；字段错误返回 `fieldErrors`；可恢复命令须能关联原 `recordId` 或请求幂等标识。不得在异常栈中返回原始账号或凭证。

| 错误码（建议） | 展示 / 行为 | 恢复 |
|---|---|---|
| `USER_NOT_FOUND` | F-02 | 修改完整账号 |
| `PROXY_NOT_FOUND` | F-03 | 修改 IP |
| `PROXY_OWNER_MISMATCH` | F-04 | 核对用户与代理 |
| `PROXY_NOT_ELIGIBLE` | F-05 / F-06 | 根据结构化原因更新卡片 |
| `NO_MATCHING_PROXY` | F-08；返回 failed 记录 | 保留输入；库存恢复后重新提交新命令 |
| `VERSION_CONFLICT` | F-07 | 重新查询，禁止自动覆盖 |
| `SYNC_SUPERSEDED` | T-04 / 被替代行状态 | 不重试旧任务 |
| `UNAUTHENTICATED` | 登录已失效，请重新登录 | 登录后查询原命令结果，不自动重复提交 |
| `FORBIDDEN` | 您没有权限执行此操作 | 刷新权限，停止写入 |
| `INTERNAL_ERROR` / 网络超时 | 无法确认更换结果，请稍后刷新记录查看 | 按原请求标识查询；不能推断资产已回滚 |

### 6.3 异步任务约定（建议）

- 新资产归属提交成功后返回持久化任务标识；结果仍为 syncing，不能提前返回 success。
- 任务终态需确认环境代理及指纹两类更新。客户端离线、重启、云环境不可用、部分成功的回执协议见 O-04。
- 可使用轮询或推送更新记录；具体间隔、超时、自动重试及次数由技术评审确定，不新增未经确认的 5 秒轮询或无限自动重试承诺。
- 离开页面可停止前端观察，但不能取消已生效资产或丢弃后台任务；返回时拉取权威结果。
- 同步无下载文件、无任务产物 URL、无任务中心新页面需求。

## 7. 异常、边界与降级

| 场景 | 原型现状 / 生产要求 | 恢复 |
|---|---|---|
| 首次加载失败 | 框架有模块加载错误；真实列表接口错误尚未模拟。生产建议数据区显示“记录加载失败，请重试” | 保留路由及条件，重新加载 |
