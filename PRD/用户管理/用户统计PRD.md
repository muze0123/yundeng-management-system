## 0. 文档控制

### 0.1 已确认决策

1. “用户”指已生成平台 `user_id` 的注册账号，不等同于团队成员、企业成员或成员关系记录。
2. 同一 `user_id` 即使加入多个团队或企业，任一用户规模指标仍只计 1 人。
3. 邀请后尚未完成注册、只有 `member_id` 而没有 `user_id` 的成员，不进入用户统计。
4. 页面只展示聚合结果，不展示姓名、手机号、邮箱、证件、IP、设备指纹等用户直接身份信息。
5. 首版为 PC 后台页面，复用 `Prototype/系统框架.html` 的 App Shell；原型交付为单文件 HTML。

### 0.2 术语

| 术语 | 定义 |
|---|---|
| 注册用户 | 已完成注册并生成有效 `user_id` 的账号；排除测试账号、合并别名账号和注册回滚记录 |
| 有效活跃 | 用户产生至少一次服务端标记为 `is_valid_activity=true` 的业务行为；纯曝光、心跳、失败请求不计入 |
| 期间活跃用户 | 统计周期内产生有效活跃的去重 `user_id` 数 |
| 新增注册用户 | 统计周期内首次完成注册的去重 `user_id` 数 |
| 成熟 cohort | 注册日加目标留存天数不晚于数据截止日的注册 cohort |
| 7 日留存 | 注册日后第 7 个北京时间自然日产生有效活跃的用户占成熟注册 cohort 的比例 |
| 账号归属 | 用户当前是否关联至少一个有效团队/企业成员关系；只用于筛选和结构分析，不改变去重主键 |
| 数据截止时间 | 当前查询结果已经完整处理到的事件时间，可能早于页面刷新时间 |

## 1. 需求概述

### 1.1 问题陈述

运营、产品和管理者当前缺少统一入口判断平台注册用户的规模、增长、活跃、留存和账号结构。若把团队成员数、注册账号数和每日活跃次数混用，会导致同一用户因加入多个组织被重复统计；若未标明数据截止时间、对比期和留存成熟度，又容易把未完结周期误判为下降。

### 1.2 产品目标

提供一个口径透明、权限受控、可筛选和可导出聚合结果的用户统计页面，使有权限人员能够：

1. 判断累计用户规模、期间新增、期间活跃和 7 日留存；
2. 比较当前周期与上一等长周期的变化；
3. 查看增长、活跃、注册来源、账号状态、账号归属和地区结构；
4. 查看按注册日组织的留存 cohort，并识别未成熟周期；
5. 在加载、空数据、查询失败、数据过期和无权限时得到明确反馈；
6. 导出当前筛选条件下的聚合数据，且不泄露用户身份。

### 1.3 成功指标

| 指标 | 定义 | 目标 | 统计周期 | 数据来源 |
|---|---|---|---|---|
| 页面查询成功率 | 成功返回全部必需统计区块的查询数 / 查询总数 | ≥99.5% | 日 | 查询网关日志 |
| 首屏可用时长 | 从路由进入到 KPI 和第一张趋势图可读的 P95 | ≤2.5 秒 | 日 | Web 性能埋点 |
| 口径查看率 | 打开任一 KPI 口径说明的访问用户数 / 页面访问用户数 | 仅观测 | 周 | 前端埋点 |
| 聚合导出成功率 | 成功生成的导出任务数 / 已提交导出任务数 | ≥99% | 日 | 导出任务表 |

成功指标用于评估页面能力，不改变业务指标口径。

### 1.4 用户与场景

| 场景 ID | 角色 | 触发 | 成功结果 |
|---|---|---|---|
| S-01 | 平台管理员 | 进入用户统计 | 默认看到最近 30 天、全部账号的核心指标和趋势 |
| S-02 | 产品/运营分析人员 | 调整日期、账号状态、注册来源或账号归属 | 所有 KPI、图表和表格使用同一筛选快照刷新 |
| S-03 | 管理者 | 查看环比和留存 | 能区分增长、不可比和未成熟周期，不把不完整数据当最终结论 |
| S-04 | 有导出权限的运营 | 导出聚合结果 | 生成带筛选摘要和口径版本的聚合文件，不含用户身份 |
| S-05 | 无查看权限人员 | 访问路由 | 显示无权限状态，不请求或缓存统计数据 |

### 1.5 范围

**本期包含**：全局筛选、四项 KPI、规模与活跃趋势、用户结构、留存 cohort、聚合数据表、刷新、聚合导出、加载/空/错误/过期/无权限状态、权限校验、审计和页面埋点。

**本期不包含**：用户明细名单、用户画像、直接身份搜索、用户 CRUD、成员管理、团队成员数量、预测增长、自动归因、营销触达、实时秒级大屏、自助 SQL。

## 2. 入口、路由与用户流程

### 2.1 入口与导航

- 侧栏路径：用户管理（灰色静态分组）→ 用户统计（一级菜单）。
- 原型文件：`用户统计.html`；菜单路由标识：`user-statistics`。
- 当前页面仅“用户统计”高亮；“用户管理”分组不可点击、不可折叠、无选中态。
- TopBar 上下文显示“用户管理 / 用户统计”；业务内容区不重复面包屑。

### 2.2 默认进入流程

```text
进入 /users/statistics
→ 校验会话与 user.statistics.read
→ 获取筛选枚举和数据权限
→ 以最近 30 天、全部账号状态、全部注册来源、全部账号归属生成查询快照
→ 并行获取摘要、趋势、结构、留存
→ 展示数据截止时间、时区和质量状态
→ 用户查看、筛选、刷新、切换分析 Tab 或导出聚合结果
```

### 2.3 查询流程

1. 用户修改筛选条件时只更新草稿，不立即请求。
2. 点击“查询”或在最后一个筛选控件按 Enter，深拷贝筛选条件为 `querySnapshot`。
3. 前端取消旧请求或使旧 `requestId` 失效；新响应仅在筛选快照仍匹配时渲染。
4. 查询期间保留卡片稳定尺寸并显示局部骨架；禁止重复提交查询。
5. 全部必需区块成功后更新 URL 查询参数、数据截止时间和“最后刷新时间”。
6. 单个非必需区块失败时保留其他区块，并在失败区块内提供重试；摘要或权限上下文失败时显示整页错误。

### 2.4 导出流程

1. 点击“导出”打开确认 Dialog，展示当前日期、筛选维度、预计文件内容和聚合数据声明。
2. 用户确认后创建导出任务；提交按钮进入 loading 并防重复点击。
3. 成功后提示“导出任务已创建，可在任务列表查看”，关闭 Dialog；页面筛选和滚动位置保持不变。
4. 失败时 Dialog 保持打开并显示原因，可重试或取消。
5. 导出只包含当前 `querySnapshot` 的 KPI、日粒度趋势、结构分布和成熟留存 cohort，不包含任何用户级记录。

## 3. 页面整体布局

### 3.1 页面骨架

```text
AppShell
├─ Sidebar：220px 展开 / 68px 折叠
├─ TopBar：56px
└─ MainContent：bg-page、16px 内边距、唯一纵向滚动容器
 ├─ FilterSection
 │ └─ 统计周期 / 账号状态 / 注册来源 / 账号归属 / 查询 / 重置
 └─ DataSection
 ├─ Header：用户统计 / 数据状态 / 刷新 / 导出
 ├─ KPI Grid：累计注册 / 新增注册 / 期间活跃 / 7日留存
 ├─ Analysis Tabs：规模与活跃 / 用户结构 / 留存分析
 ├─ Visualization：图表视图或数据表视图
 └─ AggregatedTable / CohortMatrix
```

### 3.2 响应式

| 宽度 | 规则 |
|---|---|
| ≥1440px | 侧栏 220px；KPI 四列；图表双列；筛选按可用宽度自然排列，最多四项/行 |
| 1280–1439px | KPI 四列；图表双列；卡片内缩但不压缩图表标题和操作 |
| 1024–1279px | 侧栏允许收起；KPI 两列；图表单列；表格横向滚动 |
| 768–1023px | 侧栏默认收起为紧凑态；筛选单列；KPI 两列；内容无页面级横向滚动 |
| <768px | 侧栏作为覆盖层开合；KPI 单列；筛选标签转为控件上方；原型仍可操作但非本期主验收宽度 |

### 3.3 筛选区

| 字段 | key / 类型 | 默认值 | 规则 |
|---|---|---|---|
| 统计周期 | `rangePreset` / enum | `last_30_days` | 最近 7 天、最近 30 天、最近 90 天；自然日闭区间；后端接口支持自定义日期，原型展示快捷周期 |
| 账号状态 | `accountStatus` / enum | `all` | 全部、正常、已停用、已冻结、已注销 |
| 注册来源 | `registerSource` / enum | `all` | 全部、官网注册、成员邀请、渠道合作、管理员创建 |
| 账号归属 | `affiliation` / enum | `all` | 全部、有组织关系、无组织关系；一个用户即使有多个关系仍只计一次 |

筛选字段使用 `filter-flow`：每项 500px，由 88px 右对齐标签、12px 间距和 400px 控件组成；查询/重置紧跟最后一个条件并作为不可拆分操作组换行。

### 3.4 数据区 Header

- 标题：“用户统计”，16px/600，与操作按钮同一行。
- 状态信息：“数据截止 YYYY-MM-DD HH:mm · 北京时间 · 口径 V1.0”。
- 数据完整时使用 success 语义；统计周期包含当日时显示 warning Badge“今日未完结”。
- “刷新”保留筛选并重新请求；“导出”需要 `user.statistics.export`，无权限时隐藏而不是仅禁用。

### 3.5 KPI

| KPI | 公式 | 对比 |
|---|---|---|
| 累计注册用户 | 截至筛选结束日 23:59:59，`COUNT(DISTINCT user_id)`；排除测试账号、合并别名和注册回滚 | 展示本期净增，不展示累计值环比百分比 |
| 新增注册用户 | 注册完成时间落在筛选周期内的去重 `user_id` 数 | 与紧邻前一等长周期比较；基期为 0 时显示“不可比” |
| 期间活跃用户 | 周期内至少一次 `is_valid_activity=true` 的去重 `user_id` 数 | 与前一等长周期比较；不可将每日活跃相加得到该值 |
| 7 日留存率 | 成熟 cohort 中，第 7 个自然日有效活跃的用户数 / 成熟新增注册用户数 | 与前一等长成熟 cohort 比较；无成熟分母显示“—” |

每张 KPI 显示值、单位、对比说明、数据完整性和口径 Tooltip；点击 KPI 只切换当前页相应分析 Tab 或聚合表，不跳转到用户明细。

### 3.6 分析 Tab

#### 3.6.1 规模与活跃

- 用户增长趋势：日新增注册用户柱线与累计注册用户折线；双轴均明确单位。
- 活跃趋势：日活跃用户与 7 日滚动活跃用户；日活跃按自然日去重，滚动活跃按过去 7 个自然日窗口去重。
- 提供“图表视图 / 数据表视图”切换；两者使用同一响应结果，不重复请求。
- 日粒度聚合表字段：日期、新增注册、累计注册、日活跃、7 日滚动活跃、次日留存、7 日留存、数据状态。

#### 3.6.2 用户结构

- 注册来源分布：按当前筛选周期内新增用户计算；选择单一来源时只显示该来源。
- 账号状态分布：按筛选结束时点的累计注册用户快照计算。
- 账号归属分布：有组织关系 / 无组织关系互斥；一个用户只进入一个桶。
- 地区分布：按账号最近一次合规归属地区的省级聚合；未知值统一为“未知”，不得用 IP 精确定位替代。
- 结构表字段：维度、分组、用户数、占比、期间新增、期间活跃、活跃率。

#### 3.6.3 留存分析

- cohort 行按注册日排列，列为注册当日、次日、第 3 日、第 7 日、第 14 日、第 30 日。
- 注册当日显示 cohort 人数；后续列显示留存率并在 Tooltip 中提供分子/分母。
- 未到观察日的单元格显示“未成熟”，不显示 0，不参与均值和环比。
- cohort 分母为当日新增注册用户，筛选中的账号状态按“当前快照状态”处理并在结果口径中注明。
- 小于隐私阈值 10 的 cohort 显示“<10”，留存率显示“—”。

### 3.7 分页与表格

- 日粒度表默认 10 条/页，可选 10/20/50；页码 ≤7 全显示，>7 折叠。
- 筛选、Tab 或页大小变化后回到第 1 页；删除场景不适用。
- 所有列左对齐；日期、数量、比例使用 JetBrains Mono；表格外层横向滚动。
- 当前页无结果显示内容区 Empty，不弹“查询成功”或“暂无结果”Toast。

### 3.8 正式文案

| 场景 | 文案 |
|---|---|
| 默认空 | 当前统计周期暂无用户数据 |
| 筛选空 | 当前筛选条件下暂无用户数据 |
| 网络错误 | 用户统计加载失败，请稍后重试 |
| 数据过期 | 当前结果可能已过期，请刷新后再导出 |
| 无权限 | 暂无用户统计查看权限 |

| 对比不可计算 | 不可比 |

## 4. 权限与安全

### 4.1 权限矩阵

| 能力 | 权限码 | 平台管理员 | 产品/运营分析 | 客服/普通成员 |
|---|---|---|---|---|
| 查看聚合统计 | `user.statistics.read` | 允许 | 按授权范围允许 | 默认不允许 |
| 导出聚合统计 | `user.statistics.export` | 允许 | 单独授权 | 不允许 |
| 查看全平台范围 | `user.statistics.scope.all` | 允许 | 默认不允许 | 不允许 |

服务端必须同时校验权限和数据范围；前端隐藏按钮不是授权依据。无查看权限时不得发起 KPI、趋势、结构或留存请求。

### 4.2 隐私与审计

1. 页面响应不得返回姓名、昵称、手机号、邮箱、证件号、完整 IP、Cookie、设备指纹或代理凭证。
2. 所有分布均为聚合值；分组人数小于 10 时返回 `suppressed=true`，前端显示“<10”。
3. 导出文件包含操作者、生成时间、筛选摘要、时区、口径版本和数据截止时间；下载链接 24 小时失效。
4. 查询日志记录 `operatorId`、权限范围摘要、筛选快照哈希、requestId 和耗时，不记录用户明细。
5. 导出创建、下载、失败和过期均写审计日志。

## 5. 数据模型与业务规则

### 5.1 查询快照

```json
{
 "startDate": "2026-07-15",
 "endDate": "2026-08-13",
 "timezone": "Asia/Shanghai",
 "accountStatus": "all",
 "registerSource": "all",
 "affiliation": "all",
 "metricVersion": "user-statistics-v1.0"
}
```

### 5.2 核心事实

| 对象 | 主键 | 必需字段 | 规则 |
|---|---|---|---|
| 用户账号事实 | `user_id` | `registered_at`、`status`、`register_source`、`is_test` | `user_id` 是唯一去重键 |
| 用户活跃日事实 | `user_id + activity_date` | `is_valid_activity`、`first_activity_at` | 每用户每天最多一条有效聚合记录 |
| 组织关系快照 | `user_id + snapshot_date` | `active_relation_count` | 仅用于“有/无组织关系”互斥分桶 |
| 留存 cohort | `register_date + user_id` | `retained_d1/d3/d7/d14/d30` | 未成熟观察日为 null，不写 0 |

### 5.3 有效活跃规则

服务端维护可版本化的有效活跃事件集合，首版至少包含：成功登录后进入工作台、成功启动浏览器环境、成功完成代理资产使用、成功执行自动化任务。页面曝光、登录页停留、心跳、轮询、失败行为和后台补数操作不计入。结果返回 `activityDefinitionVersion`，页面在口径说明中展示。

### 5.4 时间与对比

1. 所有自然日按 `Asia/Shanghai` 切分；存储时间统一 UTC，聚合时转换。
2. 快捷周期包含结束日；当结束日为今天时，结果标记“今日未完结”。
3. 对比期为当前周期之前紧邻的等长自然日区间。
4. 当前或对比周期含未完结日时，仍展示结果，但不宣称最终变化；Tooltip 显示截止时间。
5. 数据延迟目标 ≤15 分钟；超过 30 分钟标记 stale，并禁用导出。

### 5.5 数值显示

- 人数使用千分位整数；百分比保留 1 位小数。
- 分母为 0、无成熟 cohort 或隐私抑制时显示“—”。
- 绝对变化可为负数；百分比基期为 0 时显示“不可比”。
- 0 是有效结果，显示 `0` 或 `0.0%`，不得与无数据混淆。
- 图表 Tooltip 显示完整值，不使用无法还原的缩写；坐标轴可使用“万”。

## 6. 状态、异常与恢复

| 状态 | 页面表现 | 恢复 |
|---|---|---|
| 首屏 Loading | 筛选区可见且禁用；KPI 与图表保留稳定骨架 | 请求完成自动替换；10 秒超时转 Error |
| 查询 Loading | 保留旧结果并覆盖局部 loading；查询/导出禁用 | 新响应匹配快照后更新 |
| 默认 Empty | 显示“当前统计周期暂无用户数据” | 提供切换最近 90 天 |
| 筛选 Empty | 显示“当前筛选条件下暂无用户数据” | 提供重置筛选 |
| 局部 Error | 目标图表内显示 requestId 和重试 | 仅重试该区块 |
| 整页 Error | 摘要或权限上下文失败，隐藏旧数据 | 提供整页重试 |
| Forbidden | 显示缺少权限，不渲染统计组件 | 返回有权限页面 |
| Stale | 保留旧结果，顶部 warning，导出禁用 | 刷新成功后解除 |
| Export failed | Dialog 内显示错误并恢复确认按钮 | 重试或取消 |

接口超时或失败不得把旧结果标成最新；旧请求完成不得覆盖新查询。刷新和 Tab 切换不清空筛选。

## 7. 接口契约

### 7.1 接口

| 场景 | 方法与接口 | 关键响应 |
|---|---|---|
| 页面上下文 | `GET /api/v1/users/statistics/context` | permissions、filterOptions、metricVersion、activityDefinitionVersion |
| 核心摘要 | `GET /api/v1/users/statistics/summary` | kpis、comparison、dataCutoffAt、qualityStatus |
| 趋势 | `GET /api/v1/users/statistics/trends` | dates、newUsers、totalUsers、dailyActiveUsers、rolling7dActiveUsers、retention |
| 结构 | `GET /api/v1/users/statistics/distributions` | source、status、affiliation、region、suppressed |
| 留存 | `GET /api/v1/users/statistics/retention` | cohorts、maturity、privacyThreshold |
| 创建导出 | `POST /api/v1/users/statistics/export-jobs` | jobId、status、expiresAt |

公共查询参数：`startDate`、`endDate`、`timezone`、`accountStatus`、`registerSource`、`affiliation`。响应必须携带 `requestId`、`queryHash`、`metricVersion`、`dataCutoffAt`。

### 7.2 错误码

| 错误码 | 含义 | 前端处理 |
|---|---|---|
| `STATISTICS_FORBIDDEN` | 无查看权限 | Forbidden 页面 |
| `INVALID_DATE_RANGE` | 日期非法或超过 730 天 | 筛选字段错误，不发请求 |
| `QUERY_TOO_LARGE` | 查询范围或维度组合过大 | 提示缩短周期或减少维度 |
| `STATISTICS_TIMEOUT` | 聚合超时 | 保留旧结果并提供重试 |
| `DATA_NOT_READY` | 数据仍在聚合 | 显示 stale/处理中，不显示 0 |
| `EXPORT_FORBIDDEN` | 无导出权限 | 关闭 Dialog 并刷新权限上下文 |
| `EXPORT_RATE_LIMITED` | 导出频率超限 | 显示下次可重试时间 |

### 7.3 幂等与并发

- 查询为只读请求；前端以 `requestId + queryHash` 防止旧响应覆盖。
- 创建导出使用 `Idempotency-Key`，同一操作人和筛选快照 60 秒内重复提交返回同一任务。
- 同一用户最多 3 个 processing 导出任务；超过限制返回 `EXPORT_RATE_LIMITED`。

## 9. 非功能性要求

1. KPI 与第一张趋势图 P95 ≤2.5 秒；整页所有区块 P95 ≤4 秒。
2. 查询接口超时 10 秒；单区块失败不阻塞已成功区块。
3. 支持最大 730 天查询；超过 90 天时后端可按周返回趋势，但留存仍按 cohort 规则计算。
4. 页面在 1280×720、1440×900、1920×1080 和 768×1024 下不得出现元素重叠或页面级横向滚动。
5. 交互元素支持键盘焦点、Enter/Space 激活、Escape 关闭浮层；图表提供同数据源表格替代。
6. 颜色不是唯一的信息载体；趋势同时显示箭头/文字，留存单元格显示数值。
7. 原型控制台无 error；Chart.js 重绘前销毁旧实例；Lucide 图标初始化成功。

## 12. 发布、监控与回滚

1. 灰度顺序：内部数据管理员 → 10% 运营账号 → 全部有权限账号。
2. 监控查询成功率、P95 时长、空结果率、stale 比例、导出失败率和前端异常率。
3. 指标口径版本与页面版本分离；口径变更必须新增版本和生效时间，不覆盖历史解释。
4. 若新接口异常，回滚页面路由和菜单入口；不得用旧口径数据冒充新口径。
5. 导出能力可独立通过权限开关关闭，不影响页面只读统计。

## 13. 风险与边界说明

| 风险 | 影响 | 控制 |
|---|---|---|
| 成员关系与用户账号混用 | 用户规模重复或遗漏 | 所有核心指标只按 `user_id` 去重，关系仅作为筛选维度 |
| 今日数据未完结 | 环比误判 | 明确截止时间和“今日未完结”标识 |
| 留存未成熟 | 把未来观察窗当 0 | null + “未成熟”，排除均值和对比 |
| 有效活跃事件变更 | 历史趋势断层 | 返回并展示 `activityDefinitionVersion`，变更需版本化 |
| 小样本泄露 | 间接识别用户 | `<10` 隐私阈值、聚合导出、下载审计 |
| 账号状态按当前快照筛选 | 历史口径误解 | 在留存结果说明筛选按当前快照状态处理 |
