## 1. 需求概述

### 1.1 页面定位

环境管理是云登后台“资源管理”中的浏览器环境工作台，面向团队管理员、环境管理员和获授权成员，集中完成环境查找、分组、运行状态判断、启动/关闭、批量移动、授权和删除恢复。它承接环境创建、代理绑定和团队授权产生的数据，并向新建环境、环境编辑、代理管理及运行客户端输出操作上下文。

本页不负责完整的新建环境表单、指纹参数编辑、代理购买、批量导入映射和跨浏览器迁移；这些能力由独立页面或流程承接。本页不能把“点击启动”当成“启动成功”，必须等待启动前检查和启动结果返回。

### 1.2 背景与问题

浏览器环境同时关联账号、分组、代理、指纹配置、成员权限和运行实例。若列表仅展示名称而缺少运行与网络上下文，用户需要跨页面反复确认；若批量操作没有作用范围、部分失败和审计结果，容易误操作团队资产。

本需求通过统一状态 Tab、筛选区、分组导航、双视图列表、运行控制、批量操作和回收站，建立“找到环境 → 判断可用性 → 执行动作 → 获得可追溯结果”的最小闭环。

### 1.3 一句话目标与成功指标

**一句话目标：**让有权限的团队成员在一个页面内快速定位环境并完成可恢复、可审计的运行与资产管理操作，同时避免对运行中环境、无权限环境和批量对象的误操作。

| 指标 | 定义 | 基线 | V1.0 目标 | 数据来源 |
|---|---|---|---|---|
| 环境查找耗时 | 进入页面至首次打开目标环境或点击运行操作的时长中位数 | 上线前通过可用性测试建立 | 相同任务较旧流程下降 20% | `page_view`、搜索/筛选与操作事件 |
| 有效启动转化 | 通过启动前检查并持续运行 ≥60 秒的环境数 ÷ 启动点击环境数 | 由既有 ENV 事件建立 | 只作为质量观察，不预设不可靠的绝对值 | ENV-007～ENV-010 |
| 列表查询性能 | 50 条/页条件下接口成功返回并完成首屏渲染的 P95 | 无 | ≤1.5 秒 | 前端性能与接口监控 |
| 批量结果可追溯率 | 产生明确逐项结果和审计记录的批量请求 ÷ 全部批量请求 | 无 | 100% | ENV-012、审计日志 |

**数据边界：**启动点击、创建提交和代理检测点击均不是业务成功；必须以后端结果事件作为成功口径。搜索词、账号原文、代理凭证、Cookie 和指纹原值禁止进入埋点。

### 1.4 用户、角色与任务

| 用户角色 | 准入条件 | 核心任务 | 可执行范围 |
|---|---|---|---|
| 团队管理员 | 拥有团队级环境管理权限 | 管理全部授权环境、分组、成员授权和回收站 | 团队授权范围内全部环境 |
| 环境管理员 | 拥有环境查看、运行和编辑权限 | 查询、启动/关闭、编辑和移动环境 | 权限服务返回的环境集合 |
| 普通成员 | 至少拥有环境查看权限 | 使用已授权环境，查看与自身任务相关的运行信息 | 仅被授权环境；高风险操作不可见 |
| 只读审计角色 | 拥有查看与审计权限 | 查看配置摘要与最近运行信息 | 不显示任何写操作 |

### 1.5 范围与非目标

| 本期包含 | 本期不包含 | 后续/依赖 |
|---|---|---|
| 状态 Tab、关键词和多维筛选 | 完整环境创建表单 | 新建环境页 `/newBrowser` |
| 分组查看、新建/重命名/删除空分组 | 指纹参数逐项编辑 | 环境编辑页 |
| 表格/卡片视图、分页与选中态 | 代理购买和代理资源维护 | 代理列表与代理市场 |
| 单个启动、关闭、重试和编辑入口 | 批量导入字段映射、一键迁移扫描 | 独立导入/迁移流程 |
| 批量启动、关闭、移动、授权、删除 | 自动化脚本/RPA 编排 | 自动化模块 |
| 软删除、回收站恢复 | 超过 30 天后的人工恢复 | 备份与运维流程 |

### 1.6 关键边界条件

| 编号 | 触发条件 | 系统规则 | 用户可见表现与恢复路径 |
|---|---|---|---|
| B-01 | 搜索词为空 | 返回当前分组、状态和其它筛选下的默认列表 | 不报错；分页回到第 1 页 |
| B-02 | 环境处于 `running` 或 `starting` 时删除 | 服务端拒绝删除；批量操作允许其它对象继续 | 逐项显示“运行中的环境不可删除”，可先关闭后重试 |
| B-03 | 启动前检查发现代理不可用、权限失效或版本不兼容 | 不创建运行实例 | 行状态变为“启动失败”，展示明确原因与“重试/编辑”入口 |
| B-04 | 同一环境被连续点击启动 | 前端立即禁用按钮；服务端按 `launchRequestId` 幂等 | 只产生一个启动请求，按钮显示“启动中” |
| B-05 | 批量选中超过 100 条 | 禁止提交 | Toast：“单次最多选择 100 个环境” |
| B-06 | 批量操作部分成功 | 成功项提交，失败项不回滚已成功项 | Dialog 展示成功 N、失败 N；失败原因可逐项查看并重试 |
| B-07 | 删除后 30 天内 | 环境进入回收站，环境数据不在常规列表出现 | 可恢复至原分组；原分组不存在时恢复至“未分组” |
| B-08 | 权限在操作中被撤销 | 服务端返回 `FORBIDDEN`，不得继续写入 | 关闭浮层、刷新权限态并提示“您没有权限执行此操作” |
| B-09 | 列表末页数据全部被删除 | 重新计算总页数 | 自动回退到新的最后一页，避免空白页 |
| B-10 | 宽度不足以容纳表格 | 页面本身不产生横向滚动 | 仅表格容器横向滚动；侧栏可折叠 |

### 1.7 Toast 文案汇总

| 编号 | 触发条件 | 级别与正式文案 | 后续行为 |
|---|---|---|---|
| T-01 | 启动请求已提交 | 信息：“环境正在启动” | 行状态立即进入启动中，等待最终结果 |
| T-02 | 环境成功启动 | 成功：“环境已启动” | 行状态更新为运行中 |
| T-03 | 环境已关闭 | 成功：“环境已关闭” | 行状态更新为未启动 |
| T-04 | 批量请求完成 | 成功/警告：“操作完成：成功 {successCount} 个，失败 {failureCount} 个” | 刷新受影响行，失败项保持选中 |
| T-05 | 删除完成 | 成功：“环境已移至回收站” | 从常规列表移除并更新分组数量 |
| T-06 | 恢复完成 | 成功：“环境已恢复” | 从回收站移除，常规列表可查询 |
| T-07 | 网络失败 | 错误：“网络异常，请检查网络后重试” | 保留筛选、页码和选中态 |
| T-08 | 权限不足 | 警告：“您没有权限执行此操作” | 刷新权限并隐藏不可用操作 |

## 2. 信息架构、入口与用户流程

### 2.1 入口与路由

| 入口 | 前置条件 | 路由 | 初始状态 | 返回行为 |
|---|---|---|---|---|
| 侧边栏“资源管理 / 环境管理” | `environment.read` | `/account` | 全部状态、全部分组、第 1 页、列表视图 | 保留本会话最近筛选与视图 |
| 新建/编辑流程返回 | 有目标环境或创建结果 | `/account?environmentId={id}` | 定位目标环境所在分组并短暂高亮 | 清除无效深链参数 |
| 回收站入口 | `environment.restore` | `/account?view=recycle` | 展示 30 天内已删除环境 | 返回常规列表时恢复此前筛选 |

### 2.2 主流程

```text
进入环境管理 → 鉴权并加载分组、筛选枚举与环境列表
 ├─ 无权限 → 展示无权限状态
 ├─ 加载失败 → 展示错误状态与重试
 └─ 加载成功 → 选择状态/分组/筛选 → 查询并分页
 ├─ 单个环境 → 启动/关闭/编辑/移动/授权/删除
 ├─ 多选环境 → 批量启动/关闭/移动/授权/删除 → 查看逐项结果
 └─ 回收站 → 恢复环境 → 返回原分组或未分组
```

### 2.3 关键用户旅程

| 阶段 | 用户动作 | 系统响应 | 中断与恢复 | 埋点 |
|---|---|---|---|---|
| 到达 | 从资源管理进入 | 加载默认列表并显示数量 | 无权限/加载失败显示可行动状态 | `page_view`、ENV-001 |
| 查找 | 搜索、筛选或选分组 | AND 组合查询，分页回第 1 页 | 无结果保留条件并提供重置 | ENV-002、ENV-003 |
| 运行 | 点击启动 | 进入启动中，执行权限/版本/代理/实名检查 | 失败时显示检查项与重试入口 | ENV-007～ENV-010 |
| 批量 | 选中后执行操作 | 校验范围并返回逐项结果 | 部分失败不回滚成功项 | ENV-012 |
| 删除恢复 | 确认删除或从回收站恢复 | 软删除/恢复并更新总数 | 运行中拒绝删除；恢复无原分组则进未分组 | ENV-013、ENV-014 |

## 3. 页面与交互规格

### 3.1 页面整体结构

页面复用 `Prototype/系统框架.html` 的 56px 顶栏、220px 侧栏、折叠行为和全局反馈。业务内容仅在主内容区呈现，采用“筛选区 + 数据区”两个纵向区块，不设置独立页面标题卡。

```text
┌────────侧栏────────┬──────────────────顶栏──────────────────────┐
│ 资源管理 │ 资源管理 / 环境管理 账号 │
│ 环境管理（高亮） ├──────────────────────────────────────────┤
│ │ 筛选区：状态 Tab + 筛选项 + 查询/重置 │
│ ├──────────────────────────────────────────┤
│ │ 数据区标题 + 指标 + 操作工具栏 │
│ │ ┌─分组导航─┬─表格/卡片视图──────────────┐ │
│ │ │ │ 数据、空态、错误态 │ │
│ │ └──────────┴────────────────────────────┘ │
│ │ 分页器 │
└────────────────────┴──────────────────────────────────────────┘
```

### 3.2 筛选区

| 控件 | 字段 key | 类型 | 默认值 | 规则 |
|---|---|---|---|---|
| 状态 Tab | `status` | enum | `all` | 全部、运行中、未启动、启动中、异常；切换后立即查询并回第 1 页 |
| 搜索环境 | `keyword` | string, ≤50 | 空 | 匹配环境名称、环境编号、脱敏账号标识和备注；埋点禁止上报原文 |
| 代理状态 | `proxyStatus` | enum | `all` | 全部、可用、检测中、不可用、未配置 |
| 浏览器内核 | `browserKernel` | enum | `all` | 全部、Chrome 128、Chrome 127、Firefox 129 |
| 负责人 | `ownerId` | string | 空 | 仅展示有数据权限的团队成员；按 ID 查询 |
| 查询 | — | Button | — | 应用筛选；支持搜索框回车；条件之间为 AND |
| 重置 | — | Button | — | 清空筛选并恢复全部状态、当前分组、第 1 页；不改变视图模式 |

### 3.3 分组导航

| 组件 | 展示/交互规则 |
|---|---|
| 全部环境 | 显示有权限环境总数；默认选中 |
| 未分组 | 显示未归组环境数 |
| 自定义分组 | 显示分组名称与直属环境数；点击后应用 `groupId` 筛选 |
| 新建分组 | 名称必填、去首尾空格、1～20 字；团队内同级不可重名 |
| 分组菜单 | 支持重命名、环境授权、删除空分组；非空分组删除前须先移动环境 |

### 3.4 数据区与字段

标题为“环境列表”，回收站模式改为“环境回收站”。标题右侧依次为回收站、刷新、视图切换、批量操作和新建环境；无权限按钮不展示。

| 列名 | 字段 key | 展示规则 |
|---|---|---|
| 复选框 | `selected` | 表头控制当前页全选；跨页不自动选中；选中行使用主色浅底 |
| 环境 | `name`,`environmentId` | 名称主行；编号用等宽字体；名称最多两行，悬停显示完整值 |
| 账号 | `accounts` | 展示平台图标、平台名和脱敏账号；多账号显示首个 +N |
| 分组 | `groupName` | 空值显示“未分组” |
| 代理/IP | `proxy` | 国家/地区、脱敏 IP 与延迟；凭证永不展示；不可用用危险语义色 |
| 浏览器 | `os`,`browserKernel` | 操作系统 + 内核版本 |
| 负责人 | `ownerName` | 姓名 + 团队角色摘要 |
| 状态 | `status` | 运行中/未启动/启动中/异常；状态文字和图形共同表达 |
| 最近运行 | `lastRunAt` | `YYYY-MM-DD HH:mm`，从未运行显示“—” |
| 操作 | `permissions`,`status` | 启动/关闭、编辑、更多；按权限和状态禁用或隐藏 |

列表默认按最近运行时间倒序；从未运行环境排在有时间记录之后。支持每页 10/20/50 条，分页规则遵循 `design.md`。

### 3.5 表格与卡片视图

| 模式 | 规则 |
|---|---|
| 列表视图 `table` | 默认；高密度展示全部字段，表格容器横向滚动 |
| 卡片视图 `card` | 每张卡展示环境、账号、代理、状态、负责人和主操作；分页、筛选和选中集合与列表视图共享 |
| 切换 | 只改变呈现方式，不重新请求同一页数据；记录到当前会话，并作为 ENV-001 的 `view_mode` |

### 3.6 单个环境操作

| 编号 | 用户动作 | 前置条件 | 系统行为 | 反馈 |
|---|---|---|---|---|
| A-01 | 启动 | `status in [stopped,error]` 且 `environment.launch` | 生成 `launchRequestId`，行进入启动中，执行启动前检查 | T-01；最终成功 T-02，失败展示失败原因 |
| A-02 | 关闭 | `status=running` 且 `environment.close` | 请求关闭实例，成功后更新状态与运行时长 | T-03 |
| A-03 | 编辑 | `environment.update` | 跳转环境编辑页并携带 `environmentId` | 返回后刷新目标行 |
| A-04 | 移动分组 | `environment.move` | Modal 选择目标分组；成功后更新分组 | “环境已移动” |
| A-05 | 授权 | `environment.authorize` | Modal 选择权限级别/角色，提交前展示影响范围 | “环境授权已更新” |
| A-06 | 删除 | `environment.delete` 且非运行/启动中 | 确认后软删除 | T-05 |

删除确认正式文案：标题“确认删除该环境？”，说明“环境将移至回收站并保留 30 天。运行中的环境需要先关闭。”，按钮“取消 / 移至回收站”。

### 3.7 批量操作

批量操作仅作用于用户明确勾选的环境，最多 100 个，不以“当前筛选全部”替代已选集合。菜单项：批量启动、批量关闭、移动分组、批量授权、移至回收站。

提交前按每个环境再次鉴权并校验状态。结果必须返回 `successItems[]` 与 `failedItems[{id,code,message}]`。部分失败时保留失败项选中状态，成功项取消选中；用户可修复后重试。

### 3.8 新建环境入口

点击“新建环境”展开创建方式菜单：单个添加、批量添加、批量导入、一键迁移。选择后跳转到既有路由：

## 4. 权限、可见性与数据安全

| 资源动作 | 团队管理员 | 环境管理员 | 普通成员 | 只读角色 | 前端表现 |
|---|---:|---:|---:|---:|---|
| 查看授权环境 | 是 | 是 | 是 | 是 | 无权限时菜单隐藏；直达展示无权限状态 |
| 启动/关闭 | 是 | 是 | 按环境授权 | 否 | 无权限隐藏主操作 |
| 编辑/移动 | 是 | 是 | 按环境授权 | 否 | 无权限隐藏 |
| 环境授权 | 是 | 按角色配置 | 否 | 否 | 无权限隐藏 |
| 删除/恢复 | 是 | 按角色配置 | 否 | 否 | 二次确认；服务端兜底 |
| 分组管理 | 是 | 按角色配置 | 否 | 否 | 分组菜单按权限裁剪 |

服务端必须对每个环境执行对象级鉴权，不能信任前端传入的团队或分组。账号仅展示脱敏标识；代理 IP 可按业务权限脱敏，用户名、密码、Token、Cookie、LocalStorage、指纹原值不得进入列表响应、日志、错误信息或埋点。

## 5. 数据模型、业务规则与状态机

### 5.1 领域对象

| 对象 | 唯一标识 | 核心字段 | 关系 |
|---|---|---|---|
| Environment | `environmentId` | 名称、分组、代理、内核、状态、负责人、版本 | 属于团队，可关联多个账号 |
| EnvironmentGroup | `groupId` | 名称、环境数、授权策略 | 团队内一对多环境 |
| RuntimeInstance | `instanceId` | 启动请求、运行状态、开始/结束时间、退出码 | 一个环境同一时刻最多一个有效实例 |
| EnvironmentGrant | `grantId` | 主体、权限级别、有效期 | 环境或分组到角色/成员的授权 |
| RecycleRecord | `recycleId` | 删除人、删除时间、原分组、到期时间 | 对应一个软删除环境 |

### 5.2 环境运行状态

| code | 展示 | 进入条件 | 可执行主操作 | 语义色 |
|---|---|---|---|---|
| `stopped` | 未启动 | 新建成功、主动关闭或正常退出 | 启动、编辑、删除 | 中性 |
| `starting` | 启动中 | 启动请求已受理 | 无；允许查看检查进度 | info |
| `running` | 运行中 | 浏览器实例启动成功 | 打开、关闭；禁止删除 | success |
| `error` | 异常 | 预检失败、启动失败或实例异常退出 | 重试、编辑、查看原因 | danger |
| `deleted` | 已删除 | 软删除成功 | 恢复 | 中性 |

```text
stopped ──启动──> starting ──成功──> running ──关闭/正常退出──> stopped
 └─失败──> error ──重试──> starting
stopped/error ──删除──> deleted ──恢复──> stopped
```

### 5.3 业务规则

| 编号 | 规则 | 实现责任 |
|---|---|---|
| R-01 | 所有筛选条件为 AND；值为 `all` 或空时不限制该维度 | 前后端 |
| R-02 | 每次查询、状态切换、分组切换都将页码重置为 1 | 前端 |
| R-03 | 启动前检查顺序为权限、客户端版本、运行占用、代理连通性、必要的认证状态；任一失败不创建实例 | 后端/客户端 |
| R-04 | 一个环境同一时刻最多一个有效运行实例 | 后端 |
| R-05 | 运行中和启动中环境不可删除 | 后端 |
| R-06 | 批量操作最大 100 个，允许部分成功并返回逐项结果 | 前后端 |
| R-07 | 软删除保留 30 天；恢复后运行状态统一为未启动 | 后端 |
| R-08 | 分组删除仅允许空分组；分组授权变更只影响继承该授权的环境 | 后端 |

### 5.4 并发、幂等与一致性

| 场景 | 方案 | 用户可见结果 |
|---|---|---|
| 重复启动/关闭 | `launchRequestId` / `closeRequestId` 幂等；按钮 loading | 只产生一个有效请求 |
| 多人同时编辑 | `version` 乐观锁 | 提示“环境已被他人修改，请刷新后重试” |
| 删除与启动并发 | 服务端事务内检查最新运行状态；运行保护优先 | 删除失败且环境保持可用 |
| 批量部分失败 | 逐项执行并返回结果，不用单一总事务回滚全部 | 成功项生效，失败项可重试 |
| 分页期间数据变化 | 响应返回服务端总数；末页空时自动回退 | 不停留在不存在的页码 |

## 6. 接口与前后端契约

以下路径为产品语义建议，最终以 OpenAPI 为准，但字段语义与错误处理不得丢失。

| 场景 | Method & Path | 关键参数 | 关键响应 | 失败语义 |
|---|---|---|---|---|
| 列表查询 | `GET /api/v1/environments` | `page,pageSize,status,keyword,groupId,proxyStatus,browserKernel,ownerId,view` | `items,total,permissions` | `INVALID_FILTER`,`FORBIDDEN` |
| 分组列表 | `GET /api/v1/environment-groups` | `includeCounts=true` | `groups,totalCount,ungroupedCount` | `FORBIDDEN` |
| 启动 | `POST /api/v1/environments/{id}/launch` | `launchRequestId,version` | `status,precheck,instanceId` | `ALREADY_RUNNING`,`PROXY_UNAVAILABLE`,`AUTH_REQUIRED` |
| 关闭 | `POST /api/v1/environments/{id}/close` | `closeRequestId,instanceId` | `status,runDurationSec` | `NOT_RUNNING`,`INSTANCE_CHANGED` |
| 批量操作 | `POST /api/v1/environments/batch-actions` | `action,environmentIds,payload,requestId` | `successItems,failedItems` | `BATCH_LIMIT_EXCEEDED` |
| 软删除 | `DELETE /api/v1/environments/{id}` | `version,requestId` | `recycleId,expiresAt` | `ENVIRONMENT_RUNNING`,`VERSION_CONFLICT` |
| 恢复 | `POST /api/v1/environments/{id}/restore` | `requestId` | `environmentId,groupId,status` | `RETENTION_EXPIRED`,`NAME_CONFLICT` |
| 分组写操作 | `POST/PATCH/DELETE /api/v1/environment-groups/{id}` | `name,version,requestId` | `group,version` | `DUPLICATE_NAME`,`GROUP_NOT_EMPTY` |

通用错误响应必须携带 `requestId`、稳定 `code` 和用户可行动的 `message`。前端只展示安全文案，不泄露代理凭证、服务器路径和内部异常栈。

## 7. 异常、边界与降级

| 场景 | 页面表现 | 系统处理 | 恢复 |
|---|---|---|---|
| 首次加载失败 | 数据区错误状态，不清空侧栏与筛选 | 记录请求标识和错误分类 | 点击“重新加载” |
| 筛选枚举局部失败 | 失败筛选项禁用并说明，其它筛选可用 | 不使用过期的权限枚举 | 刷新枚举 |
| 启动超时 | 保持“启动中”并显示“正在确认运行结果” | 以服务端/客户端最终状态对账 | 自动刷新或手动重试查询，不重复启动 |
| 代理检测服务异常 | 代理状态显示“暂不可确认” | 不把未知误判为不可用 | 允许重新检测 |
| 网络中断 | Toast T-07；保留页面状态 | 不提交或回滚未确认乐观状态 | 网络恢复后重试 |
| 权限变化 | 隐藏/禁用写操作并提示 T-08 | 中断请求并刷新权限 | 联系团队管理员 |
| 长名称/账号 | 单元格省略，Tooltip 展示完整脱敏文本 | 不撑破布局 | 表格横向滚动 |

复用既有事件，不创建同义事件：

| 事件 | 触发 | 关键属性 | 禁止采集 |

## 11. 发布、灰度与回滚

| 阶段 | 内容 | 通过条件 | 回滚条件 |
|---|---|---|---|
| 上线前 | 权限初始化、软删除字段与索引、埋点和审计验收 | AC-01～AC-08 全部通过 | 数据迁移或权限校验失败 |
