## 2. 页面结构

1. 筛选区：14 项条件，搜索、重置、展开/收起。
2. 数据区：标题“套餐订单”与结果数同行，下方表格，右下方分页器。
3. 只复用根入口的公共顶栏、侧栏和路由，不复制系统壳、不使用 iframe。
4. 与代理订单筛选区保持一致（v2.2）：auto-fit 栅格每列最小480px、列/行间距16px；标签列固定112px右对齐且不换行（含“支付机构订单号”等长标签），控件随所在列自适应拉伸（flex:1 1 0），不再使用88px标签+300px固定控件。
5. 默认仅显示筛选第一行，依据实际可用宽度计算字段数量；按钮组始终可见并紧随条件，空间不足时整体换行。展开/收起不提交查询、不丢失条件。
6. 表格保持所有列左对齐，订单号、ID、手机号、金额、日期、时长和数量用等宽字体。宽表在卡片内部横向滚动；768px 不产生页面级横向溢出。

### 3.1 支付方式

- 基础项：余额、支付宝、微信、返佣充值、CDK兑换、线下支付、赠送、代理商。
- 海外支付：KZYH、PAYPAL贝宝、STRIPE。
- 数字货币：POLY_USD、TRX_USD、SOL_USD。
- 最后一项：系统赠送。
- “海外支付”“数字货币”为分组标题，子项缩进并独立复选。已选多个方式为 OR 匹配，与其他字段为 AND 匹配。
- 面板可滚动，固定定位并限制在视口内，不裁切、不撑高页面；支持清空、点击外部和 Escape 关闭。

### 3.2 搜索、日期及重置

- 搜索或在文本字段按 Enter：统一应用当前全部条件，回到第1页。
- 输入字段采用不区分大小写的包含匹配，查询时去除首尾空格，最多64字符；有值时出现清空图标，清空后保留焦点。
- 本原型对脱敏后的示例账号匹配，不包含隐藏明文；可用可见片段（如手机号尾号）测试。生产接口应由服务端对经授权的账号查询做匹配，返回值仍脱敏。
- 日期范围为双月日历，按 Asia/Shanghai 自然日包含起止日期；未支付或无到期时间的订单不匹配对应非空日期范围。
- 首次点日期选开始，第二次选结束；逆序时交换，同日可作为完整区间。只有开始而没有结束时不能确定。
- 月份切换、日期选择、清空和确定只修改草稿，需搜索后才影响结果；取消、外部点击、Escape 丢弃未确定日期。
- 重置清空全部条件，回第1页；保留每页条数和展开状态。
- 无结果显示“未找到匹配订单”及“重置筛选”。

### 4.1 套餐信息气泡

- 套餐信息参数右侧为Lucide圆圈感叹号按钮；鼠标移入或键盘聚焦显示当前行套餐明细，点击也可打开。
- 气泡固定定位于表格滚动区域之外，并限制在视口内，横向滚动不裁切气泡；移出、失焦或Escape关闭，可将指针移到气泡内阅读。
- 明细来自每行Mock对象，环境总数与三类环境数之和、成员总数与三类成员数之和一致。
- 用户指定的首行气泡示例与新增赠送列示例分别保留，不在原型中推断两者的统计时点或跨字段业务关系。

```text
环境数 x 20
-计费环境数 x 10
-免费环境数 x 10
-赠送环境数 x 0
成员数 x 5
-计费成员数 x 3
-免费成员数 x 0
-赠送成员数 x 2
```

### 4.2 筛选控件焦点规范

- 文本、单选、多选及日期触发器统一使用32px高度、4px圆角、line边框、14px文字。
- 获得焦点时只使用primary边框与 `0 0 0 2px rgba(0,102,255,.12)` 浅色光晕，不叠加额外outline，避免双蓝色描边。
- 单选箭头使用Lucide样式的SVG，控件宽度随筛选列自适应拉伸，与代理订单筛选区一致。

## 5. 数据、分页与状态恢复

- 默认按创建时间倒序，15条示例覆盖全部10种订单状态、两种支付状态、两种订单类型及主要渠道。
- 第一条更新为用户本次参数示例：环境20、成员5，赠送环境10、赠送成员2；订单金额￥210.00，折扣-￥0.00、原套餐抵扣-￥100.00、优惠券抵扣-￥10.00、应付￥100.00。Mock中应付金额=订单金额−三项抵扣。
- 其余数据为推断补全的演示快照；不代表真实交易、实际计费、退款结算或权益状态。
- 分页默认20条/页，可选10、20、50。切换每页条数回第1页，支持上一页、下一页、页码和Enter跳页。
- 跳页输入默认1，跳转后恢复1；非法页码显示有效范围并恢复1。
- 模块在会话内保存已应用条件、草稿、页码、每页条数及折叠状态。公共框架恢复有效滚动位置；刷新、导航切换、前进后退可恢复列表上下文。
- 公共 document 事件与 ResizeObserver 在离开模块时清理。
