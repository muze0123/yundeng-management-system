# 用户列表 PRD

> 本文档记录「用户列表」原型的业务规则与交互。2026-09-14 起，页面接入统一系统框架（`index.html?page=user-list`），业务实现在 `Prototype/modules/user-list.js`（含 `before` 运行时补丁）。

## 一、批量操作

批量按钮：一键复制 / 取消测试 / 设为测试 / 修改来源 / 取消禁用 / 设置禁用。

- 点击【修改来源】【取消禁用】【设置禁用】时，若未勾选任何用户，Toast 提示「请选择用户」，不打开任何弹窗。
- 勾选用户后：
  - 【修改来源】打开「修改用户来源」弹窗（来源唯一标识码或 linkuuid 必填）。
  - 【设置禁用】打开禁用确认 Dialog（取第一个选中用户）。
  - 【取消禁用】Toast 提示「已为 N 个用户取消禁用」。

## 二、列头「?」说明气泡（鼠标移入显示）

| 列 | 说明文案 |
|---|---|
| IP风控等级/IP风控标签 | IP风险等级：0待查询，1-4；越小风险越高。IP风控标签：多个标签用逗号分隔 |
| 成员数 | 当前用户下所有企业累计成员总数。例如：同一个成员同时加入 A、B 两个企业，会计算 2 个成员。A企业：企业主+成员张三 = 1个成员；B企业：企业主+成员张三 = 1个成员；成员数 = 1+1 = 2 |
| 环境数 | 当前用户下所有企业累计创建的环境数量/绑定代理数。例如：企业A 创建6个环境，其中2个使用官方代理；企业B 创建4个环境，其中3个使用官方代理；显示为 10/5。（绑定代理数按"使用官方代理的环境记录数"统计，非按 proxy_id 去重的代理数） |
| 套餐数 | 当前用户下所有企业累计环境数/套餐环境数，累计成员数/套餐成员数 |
| 赠送环境数 | 当前用户下所有企业累计赠送的环境数。例如：企业A 赠送6个环境；企业B 赠送4个环境；赠送环境数为 10 |
| 赠送成员数 | 当前用户下所有企业累计赠送的成员数。例如：企业A 赠送6个成员；企业B 赠送4个成员；赠送成员数为 10 |

## 三、参数「!」明细气泡（鼠标移入数值右侧 ! 图标显示）

| 列 | 气泡内容 |
|---|---|
| ID | 用户Id / 企业Id（按当前行展示） |
| 成员数 | 总成员数：12；表格：企业ID / 企业名称 / 成员数（按企业逐行展示） |
| 环境数 | 创建的环境数量/绑定代理数：12/6；表格：企业ID / 企业名称 / 创建环境数 / 绑定代理数 |
| 套餐数 | 表格：企业ID / 企业名称 / 累计环境数 / 套餐环境数 / 累计成员数 / 套餐成员数 |
| 赠送环境数 | 赠送环境数：12；表格：企业ID / 企业名称 / 赠送环境数 |
| 赠送成员数 | 赠送成员数：12；表格：企业ID / 企业名称 / 赠送成员数 |

明细数值与单元格取值同源，均为按企业逐行汇总的演示数据。

## 四、企业信息弹窗

「企业ID/企业名」列点击【查看】，弹出新弹窗「企业信息」：表格展示该用户名下全部企业的 企业ID（32 位 hex）、企业名称。支持 × / 点击遮罩 / Esc 关闭。

## 五、数值展示规则

- 套餐数：两行显示，第一行「累计环境数/套餐环境数」，第二行「累计成员数/套餐成员数」（如 10/10 换行 1/1）。
- 环境数：单行「创建环境数/绑定代理数」（如 12/6）。
- 套餐周期、赠送周期：两行显示，格式「YYYY-MM-DD HH:mm:ss 至⏎YYYY-MM-DD HH:mm:ss」。
- 列顺序：…套餐数 / 套餐周期 / 赠送环境数 / 赠送成员数 / 赠送周期 / 是否被邀请…

## 六、既有能力（摘要）

- 筛选区 23 项条件，双月日历日期范围选择器，查询/重置/展开收起。
- 今日统计 KPI 横向滚动条。
- 返佣比例列：列头「?」说明气泡、行内编辑弹窗（比例 / 生效时间 / 有效期）。
- 行内操作：设为测试 / 修改来源 / 设置禁用 / 禁止支付。
- 分页器：页码、每页条数（10/20/50）、跳页。
