### 本轮踩坑（重要，可复用）
1. **`form.reset()` 不复位 `<input type="hidden">`**：日期区间由隐藏域承载，用 `form.reset()` 做「重置」会导致重置后日期条件残留。已改为 `clearForm()` 显式逐控件清空（`select` 用 `selectedIndex=0`，其余置 `''`）。**注：`rebate-management.js` 存在同类潜在问题，未改动，待确认后统一处理。**
2. **标签映射漏配渲染出 `undefined`**：`tags` 数组含 `self` 但 `TAG_LABEL` 只有 `platform`/`static`，导致自有代理行渲染出字面量 `undefined` 徽标。修复为 `tags.filter(t => TAG_LABEL[t])`。**这是冒烟测试「标签文案仅允许平静」断言抓出来的，纯静态检查抓不到。**
3. **jsdom 30 移除了 `ResourceLoader` 与 `resources:'usable'`**，改用 `resources: { interceptors: [requestInterceptor(fn)] }`；`requestInterceptor` 是 jsdom 顶层导出。集成测试用它对非本地 URL 返回空 `Response` 以阻断 CDN。
4. **jsdom 默认视口 1024px < 框架 1100px 侧栏自动收起阈值**，会导致侧栏被判为紧凑态、子菜单折叠。集成测试需用 `beforeParse(window)` 在脚本执行前把 `innerWidth` 固定为 1440。
5. **jsdom 未实现 `Element.scrollBy/scrollTo/scrollIntoView`**，框架 `ensureSubmenuVisible` 会抛 `nav.scrollBy is not a function`。集成测试 `beforeParse` 中补 polyfill，否则「无控制台错误」断言会被 jsdom 缺陷污染。

## 修复：返佣管理筛选控件「双蓝色描边」（2026-10-10 下午）
- **根因**：模块样式里两条规则在同一元素上叠加 —— ①`.rm-module :is(button,input,select):focus-visible{outline:2px solid #0066FF;outline-offset:2px}`（宽泛 outline 环）；②`.rm-module .control:focus{border-color:#0066FF;box-shadow:0 0 0 2px rgba(0,102,255,.12)}`（box-shadow 环）。文本输入框即使鼠标点击也命中 `:focus-visible`，故出现 2 个蓝环。`系统框架.css` / `app-shell.js` / `index.html` **均无全局 focus 规则**，问题纯在模块内。

## 代理异常日志：筛选区「两个蓝色描边」修复 + 规范落地 + 守卫工具（2026-10-10 晚）
- **缺陷根因**：模块同时声明了 `.pel-module .control:focus { box-shadow:0 0 0 2px rgba(0,102,255,.12) }`（柔光环）与 `.pel-module :is(button,input,select):focus-visible { outline:2px solid #0066FF }`（实心描边）。`:focus-visible` 对文本输入框恒定命中（鼠标点击也命中），故两套指示必然叠加。特异性核验：`:is(button,input,select):focus-visible` = (0,2,1) > `.control` 基类 (0,2,0)，所以自定义描边赢过基类；`.control:focus` = (0,3,0) 独立给出光环。
- **修复写法**（`Prototype/modules/proxy-exception-log.js`）：
  - `.pel-module .control:focus-visible,.pel-module .pg-jump-input:focus-visible{outline:none;outline-offset:0}`
  - 描边规则收窄为 `:is(button,input,select):not(.control):not(.pg-jump-input):focus-visible`
- **⚠️ 关键前提（最易漏）**：只靠 `:not(.control)` 排除**并不充分**——UA 样式表会对 `:focus-visible` 施加默认焦点环（Chrome `outline:auto`）。真正让排除生效的是 **`.control` 基类里的 `outline:none`**（作者样式优先于 UA 样式）。删掉基类重置 → 以「柔光环 + UA 默认环」形式复现双描边，而描边规则文本上完全看不出问题。已在 smoke-test 段 J 加「`.control` 基类已 outline:none」前提断言（负向对照已验证：剥掉后断言转 false）。
